# A01 · 工作流

> 这份文档回答「**怎么把一件事做完**」：命令怎么敲、面板怎么看、URL 怎么读。
> 内部规则（槽位定义、预览壳组装、历史条数）在 [[A02-内置变量与函数]]。

## 1. 面板 URL：用户贴链接时先解码出意图

面板的路由词汇**两个模块共用**（html / svg 长得一模一样，只换首段）：

| URL | 含义 | 落点 |
| --- | --- | --- |
| `#/html` | 根目录 | 全部分组的最外层 |
| `#/html/dir/<组路径>` | 某个**文件夹** | 分组路径（可 1~8 段，如 `ui/buttons`） |
| `#/html/edit/<组路径>/<资源名>` | 某个**资源的编辑页** | 组 + 名 |

**解析规则**：首段是域（`html` / `svg`）；`dir` 段后面全是分组路径；
`edit` 段后面「末段是资源名，前面几段是分组路径」。段是 **percent-encoded**，
用之前先解码。

### 例子：用户给一个链接说「添加资源」

> 用户：给 `http://127.0.0.1:7869/#/svg/dir/%E6%B5%8B%E8%AF%95` 添加资源

要读出四件事，别反问「你指的是哪个分组」：

| 读出 | 值 | 依据 |
| --- | --- | --- |
| 哪个模块 | **svg**（不是 html） | 首段 `svg` |
| 什么操作 | 进到某个目录 | 第二段 `dir` |
| 哪个分组 | `测试` | `%E6%B5%8B%E8%AF%95` 解码后就是「测试」 |
| 该做什么 | 在 `测试` 分组里**新建资源** | 「添加资源」+ 落在 dir 上 |

于是直接执行（`svg` 模块用 `svg` 子命令；分组已存在，不必先建）：

```bash
node bin/ft.mjs svg add 测试 <资源名> --style default
```

若链接是 `#/svg/edit/测试/某图标`，则是「**改这一枚**」——落到具体资源，
通常走 `svg put 测试 某图标 --style <风格> --code -`（改代码）或 `svg rename`（改展示名）。

> 判断口诀：**落在 `dir` 上 = 往这个文件夹放东西；落在 `edit` 上 = 改这一个是具体资源。**
> 两种 URL 都能唯一确定「模块 + 分组 + 要不要指定资源名」，所以不需要再问用户。

## 2. 三步闭环

```
group add / add  →  put（写代码）  →  面板看效果（serve）
        ↑                                    │
        └──────── 不满意 → 再 put / 改风格 ←──┘
```

- **建**：`html group add <组>` → `html add <组> <名> --style <风格> --tags a,b`
- **写**：`html put <组> <名> --style <风格> --code-html - <<'EOF' … EOF`
- **看**：`node bin/ft.mjs serve` → HTML 资源 tab → 点卡片进工作台

## 3. 写多行代码：必须 heredoc（实测踩坑）

多行内容**绝不当命令行参数直接传**——跨 exec 边界会被 shell 切成只剩第一行，
后面的 flag 静默丢失。成功模板（照抄）：

```bash
node bin/ft.mjs html put ui/buttons login-btn --style minimal --code-html - <<'EOF'
<button class="btn">
  登录
</button>
EOF
```

四要素：`-` 占位、flag 全在 `<<'EOF'` **之前**、定界符**带引号**、`EOF` **顶格**。

## 4. 面板怎么用

**第一层（网盘页）**：面包屑是地址栏——点文件夹卡片下行、点面包屑回跳。
创建是**内联输入行**（点「+ 新建资源」→ 原位出现输入框 → 回车即建，只问名字）；
根目录也能直接建（自动落进「未分类」文件夹）。另有搜索 + 标签云筛选、批量操作。

**第二层（工作台）**：点资源卡片进入，**三个编辑框横向并排**（HTML / CSS / JS）
+ 下方实时预览，中间的拖拽条可以调配比。右上角是风格切换 / 新风格 / 描述 / 保存；
预览可全屏展开。左上角面包屑回跳对应目录层级。

> 面板改动**只在点保存后落盘**；CLI 立刻 `cat` 到旧内容属于正常——先去面板点保存。

## 5. 常见操作与命令

| 想做的事 | 命令 |
| --- | --- |
| 找资源（标签 AND） | `html tree --tags button,login` |
| 找资源（关键词） | `html tree --search 登录`（匹配 名 / 展示名 / 分组 / 标签 / 风格名） |
| 加第二套风格（从现有派生） | `html style add <组> <名> dark --copy-from minimal --desc 深色胶囊` |
| 切换「面板默认预览哪套」 | `html style switch <组> <名> dark` |
| 改坏了回退 | `html history list <组> <名> <风格>` → `html history restore … --entry <id>` |
| 打标签 / 去标签 | `html tag add <组> <名> --tags a,b` / `html tag rm …` |

完整命令与 flag 见 `node bin/ft.mjs routes --json`（本 skill 不复制那张表——复制出来的必然先腐烂）。
