## 新增一个 color 资源时

1. **先建组**（`color group add <组路径>`）—— 组 = 调色板集（如 `brand`、`ui/dark`）。
2. **再建调色板**（`color add <组> <调色板名> --code-data <Palette JSON>`）—— 每个资源 = 一个调色板。
3. **加色**（`color entry add <组> <调色板> <hex> [--note] [--tags]`）—— 一条命令加一色。
4. **导出**（`color export <组> --format css|json|toml|tailwind`）—— 整组出。

> 调色板 JSON 必须有 `name` / `harmony` / `colors` / `sortBy` 四个顶层字段，缺一会让面板渲染异常。空调色板的最小骨架：`{"name":"…","harmony":null,"colors":[],"sortBy":"manual"}`。

## 删除一个 color 资源时

`color entry rm <组> <调色板> <hex>` 按 hex 删一色；整段重写用 `color put --code-data <整段 JSON>`；整组删除用 `color group rm --force`。
