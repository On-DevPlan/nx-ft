# A01 · 工作流（CLI 速查）

> **CLI 一切以 `nx-ft color ...` 为前缀。** 19 条共享 CRUD/历史命令 + 4 条 color 专属命令。
> `nx-ft help color` 打印全部；`nx-ft routes --json` 给机器可读对照表。

## 常用命令（按使用顺序）

```bash
# ── 组（= 调色板集） ──────────────────────────────────────
nx-ft color group add   <组路径>            --label "展示名"   # 例: nx-ft color group add brand --label 品牌色
nx-ft color group rename <组路径>           --to <新路径>     # 改路径或只改展示名
nx-ft color group rm    <组路径>            [--force]         # 非空需 --force

# ── 资源（= 调色板） ──────────────────────────────────────
nx-ft color add   <组> <调色板名> --label "…" --code-data <Palette JSON>   # 风格缺省 default
nx-ft color load  <组> <调色板名>                                            # 看详情 + 当前 data
nx-ft color put   <组> <调色板名> --code-data <Palette JSON>                # 整段重写，风格缺省 default
nx-ft color rename <组> <调色板名> --label "新展示名" / --to <新目录名>
nx-ft color desc  <组> <调色板名> --text "场景描述"
nx-ft color tag add <组> <调色板名> --tags a,b
nx-ft color tag rm  <组> <调色板名> --tags a,b
nx-ft color rm     <组> <调调色板名> [--force]

# ── 风格（color 几乎只用 default；多套实现可加） ───────
nx-ft color style add     <组> <调色板> <风格名> [--copy-from default] [--code-data <…>]
nx-ft color style switch  <组> <调色板> <风格名>
nx-ft color style desc    <组> <调色板> <风格名> --text "…"
nx-ft color style rm      <组> <调色板> <风格名>

# ── 编辑历史（每风格最近 5 条；DATA 槽位独立） ───────
nx-ft color history list   <组> <调色板> [风格=default]
nx-ft color history read   <组> <调色板> <风格> --entry <id>
nx-ft color history restore <组> <调色板> <风格> --entry <id>

# ── 树（看全库 / 搜） ────────────────────────────────────
nx-ft color tree [--search 关键词] [--tags a,b]
```

## color 专属命令（4 条）

```bash
# 列出组内所有调色板 + 色卡（含 derivedFrom 来源标记）
nx-ft color list <组>
# 输出形如：
#   demo/  1 个调色板
#     primary  (主色板)  3 色
#       #5B7CFA  c-xxx  主色  #brand #action
#       #845EF7  c-xxx  辅助  #brand #accent
#       #15AABF  c-xxx  链接  #link
#       #AABBCC  c-xxx  ←triadic#0    ← 派生色（带来源）

# 追加一个色卡（--note / --tags 可选）
nx-ft color entry add <组> <调色板> <hex> [--note 备注] [--tags a,b]

# 删除一个色卡（按 hex；或 --id 按色卡 id 删）
nx-ft color entry rm  <组> <调色板> <hex>
nx-ft color entry rm  <组> <调色板> --id c-xxx-xxx

# 整组导出（css | json | tailwind | toml，缺省 css）
nx-ft color export <组> --format <格式>
```

## 导出格式示例（同一组，4 种格式）

```css
/* brand — 2 个调色板 */

/* 主色板 */
--主色板-1: #5B7CFA;
--主色板-2: #845EF7;
```
```json
[
  { "name": "主色板", "colors": [
    { "hex": "#5B7CFA", "note": "主色", "tags": ["brand","action"] }
  ]}
]
```
```js
// tailwind.config.js
module.exports = {
  theme: { extend: { colors: { "主色板-1": "#5B7CFA" } } }
};
```
```toml
[[palettes]]
name = "主色板"

  [[palettes.colors]]
  hex = "#5B7CFA"
  note = "主色"
  tags = ["brand", "action"]
```

## 多行 JSON：必须用 heredoc

`--code-data` 吃 JSON 字符串；多行内容**绝不当命令行参数直接传**——跨 exec 边界会被 shell 切成只剩第一行，后面的 flag 静默丢失。**成功模板**：

```bash
nx-ft color add demo primary --code-data - <<'EOF'
{
  "name": "主色板",
  "harmony": null,
  "colors": [
    { "hex": "#5B7CFA", "note": "主色", "tags": ["brand"] }
  ],
  "sortBy": "manual"
}
EOF
```

四要素：`-` 占位、flag 全在 `<<'EOF'` 之前、定界符带引号、`EOF` 顶格。

## 入参经 stdin 还是 flag？

| 场景 | 入口 | 备注 |
| --- | --- | --- |
| 一行 JSON 字符串 | `--code-data '...'` | 短调色板首选 |
| 多行 JSON | `--code-data -` + heredoc | 推荐模板 |
| 单条色卡 | `color entry add <组> <调色板> <hex>` | 不要用 put 整段写 |

## 输出格式：JSON / 人读

所有命令加 `--json` 出机器可读 JSON；不带 `--json` 走人读模板。
