# B01 · 案例：搭一个品牌主色板并导出

目标：从 0 搭一组品牌主色，落到 `brand` 组下，包含 1 个调色板、5 个色卡；导出为 CSS 变量和 Tailwind config。

## 步骤 1：建组

```bash
nx-ft color group add brand --label 品牌色
# 已创建分组: brand（品牌色）
```

## 步骤 2：建主色板

调色板必须至少有 4 个顶层字段（见 A02-数据契约）。这里先建空的：

```bash
nx-ft color add brand primary --label 主色板 \
  --code-data '{"name":"主色板","harmony":null,"colors":[],"sortBy":"manual"}'
# 已创建资源: brand/primary（风格 default）
```

> **风格缺省 `default`。** 绝大多数 color 资源只有一个 default 风格就够。非要多套实现（比如一份 JSON5 简化版 + 一份带派生规则的完整版），再 `color style add brand primary v2 --copy-from default`。

## 步骤 3：加 5 个色

```bash
nx-ft color entry add brand primary "#5B7CFA" --note 主色 --tags "brand,action"
nx-ft color entry add brand primary "#845EF7" --note 强调 --tags "brand,accent"
nx-ft color entry add brand primary "#15AABF" --note 链接 --tags "link"
nx-ft color entry add brand primary "#51CF66" --note 成功 --tags "success"
nx-ft color entry add brand primary "#FA5252" --note 危险 --tags "danger,error"
```

## 步骤 4：查

```bash
nx-ft color list brand
# brand/  1 个调色板
#   primary  (主色板)  5 色
#     #5B7CFA  c-xxx  主色  #brand #action
#     #845EF7  c-xxx  强调  #brand #accent
#     #15AABF  c-xxx  链接  #link
#     #51CF66  c-xxx  成功  #success
#     #FA5252  c-xxx  危险  #danger #error
```

## 步骤 5：导出

```bash
# CSS 自定义属性
nx-ft color export brand --format css
# /* brand — 1 个调色板 */
#
# /* 主色板 */
# --主色板-1: #5B7CFA;
# --主色板-2: #845EF7;
# --主色板-3: #15AABF;
# --主色板-4: #51CF66;
# --主色板-5: #FA5252;

# Tailwind config（可直接粘进 tailwind.config.js）
nx-ft color export brand --format tailwind
# // tailwind.config.js
# module.exports = {
#   theme: { extend: { colors: {
#     "主色板-1": "#5B7CFA",
#     "主色板-2": "#845EF7",
#     ...
#   }}}
# };

# TOML（可被 ColorStudio 的导入弹窗解析回写）
nx-ft color export brand --format toml

# 原始 JSON（保留 note / tags / createdAt / updatedAt）
nx-ft color export brand --format json
```

## 步骤 6：在 HTML / SVG 资源里引用

把 CSS 变量加到 HTML 资源的 `code-css`：

```bash
nx-ft html put ui/button primary --code-css ":root{$(nx-ft color export brand --format css | tail -n +3)}"
# 然后 html 资源里就可以用 var(--主色板-1)、var(--主色板-2)...
```

> 这是 ft-color ↔ ft-html / ft-svg 的桥：**色彩域是单一来源，其它资源域通过 CSS 变量名引用**。色板更新时所有引用点自动跟着变。

## 步骤 7：开和声（可选）

如果想让调色板多一组派生色（基于「主色」自动算三角色），编辑 `harmony`：

```bash
# 把主色（#5B7CFA）设为锚，规则 = triadic，autoFill = true
# anchorColorId 填上一步 `color list` 输出里那条主色的真实 id（形如 c-mv7zl7jm-4ry）
nx-ft color put brand primary --code-data - <<'EOF'
{
  "name": "主色板",
  "harmony": {
    "type": "triadic",
    "anchorColorId": "c-mv7zl7jm-4ry",
    "autoFill": true
  },
  "colors": [ ... 5 条原有 ... ],
  "sortBy": "manual"
}
EOF
```

> 切到「类似 / 分裂互补 / 单色」时，**派生色会就地更新 hex/rule，id 不变**——这是和声互动的「继承关系」约束。详见 A02-数据契约 的「槽位身份」一节。
