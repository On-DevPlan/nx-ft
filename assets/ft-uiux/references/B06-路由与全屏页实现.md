# B06 · 路由与全屏页实现

> 对应 A06 评分维度。**主 agent 落地实现**——给「三层路由 + 编辑页三栏 + URL 状态落地」的具体模式骨架。
> 加载本 ref 前必读 [[B00-实现总纲]] 与 [[A06-路由与全屏页评分]]。
>
> **本 ref 讲思想与模式，不绑定特定框架**。

## 实现目标

把 [[A06-路由与全屏页评分]] 要求的**三层路由 + 编辑页三栏 + URL 状态落地 + 弹窗只承担短任务**落地为路由与页面架构。

## 模式骨架

### 三层路由

```
URL 结构：
  /                          根（模块选择 / 看板入口）
  /<module>                  列表 / 看板
  /<module>/dir/<组>         分组列表页
  /<module>/view/<组>/<名>   资源详情（全屏）
  /<module>/edit/<组>/<名>   资源编辑（全屏）

判定规则：
  - 详情 / 编辑 / 对比 / 大预览 → 路由到独立路径
  - 删除确认 / 短提示 / 错误反馈 → 用弹窗（dialog 角色）
```

### 编辑页三栏布局

```
结构：
  ┌─ edit-page ──────────────────────────────────────────────────────────┐
  │  ┌─ topbar (面包屑 + 模块名 + 风格切换 + 新风格 + 保存) ────────────┐ │
  │  └──────────────────────────────────────────────────────────────────┘ │
  │  ┌─ split-container ───────────────────────────────────────────────┐   │
  │  │  ┌─ 左：元信息 ─┐ ┌─ 中：代码编辑 ─┐ ┌─ 右：实时预览 ─┐        │   │
  │  │  │             │ │                │ │              │        │   │
  │  │  └─────────────┘ └────────────────┘ └──────────────┘        │   │
  │  └──────────────────────────────────────────────────────────────┘    │
  └──────────────────────────────────────────────────────────────────────┘

关键约束：
  - 三栏之间有可拖拽分隔条（详见 [[B02-布局与分隔条实现]]）
  - 风格切换 / 新风格 / 保存按钮在右上角固定位置
  - 左 / 中 / 右三栏：元信息 / 代码 / 预览
```

### URL 状态落地

```
视图状态：
  q          搜索
  tags       标签筛选
  sort       排序
  page       分页
  batch      已选集合
  style      风格切换（编辑页）

同步规则：
  - 状态从 URL 读（页面加载时）
  - 状态变更写回 URL（用 replaceState 不污染历史栈）
  - 浏览器前进 / 后退 / 分享链接全部可复现
```

### 弹窗只承担短任务

```
弹窗允许：
  - 删除二次确认
  - 错误 / 成功 toast
  - 短提示（输入名字 / 选择标签）
  - 危险操作确认
  - 批量操作结果反馈（成功 N / 失败 N）

弹窗禁止：
  - 完整编辑表单
  - 多风格对比
  - 大预览
  - 历史回退选择

判据：弹窗关掉后内容全丢也能接受 = 短任务。否则开路由。
```

## 关键 props / state（框架无关）

| 概念 | 形态 | 说明 |
| --- | --- | --- |
| 路由表 | 框架路由配置（react-router / vue-router / sveltekit） | 三层结构 |
| 编辑页布局 | split 组件 + 三栏 | 详见 [[B02-布局与分隔条实现]] |
| URL 状态 | `URLSearchParams` + `history.pushState` | 浏览器原生 API |
| 弹窗 | `role="dialog"` + 短任务 | 任何 UI 栈都支持 |

## 框架映射（任意框架适用）

| 概念 | 实现要点 |
| --- | --- |
| 路由 | 用框架的路由 API（react-router / vue-router / sveltekit） |
| URL 同步 | 用 `URLSearchParams` + `history.pushState`（原生 API） |
| 三栏布局 | 用 [[B02-布局与分隔条实现]] 的 split 模式 |
| 弹窗 | 用 `<dialog>` 原生元素或框架组件 |

## 测试要点

- [ ] 列表 / 分组 / 详情 / 编辑都有独立路由
- [ ] URL 与面包屑双向同步（[[B04-面包屑组件实现]]）
- [ ] 视图状态（搜索 / 标签 / 排序 / 分页 / 已选）全部落 URL
- [ ] 编辑页三栏：元信息 / 代码 / 预览，中间可拖拽分隔条
- [ ] 风格切换 / 新风格 / 保存按钮在右上角
- [ ] 弹窗只承担短任务（删除确认 / toast）
- [ ] 路由切换无花哨动画，直接切换

## 反模式

| 错误做法 | 后果 | 正确做法 |
| --- | --- | --- |
| 详情 / 编辑塞进 modal | modal 里塞大预览 | 开路由 |
| 视图状态只放内存 | 刷新就丢 | URLSearchParams 落 URL |
| 编辑页用一栏布局 | 预览要拉到底 | 三栏 + SplitPane |
| 弹窗里有「保存」按钮 | 关掉弹窗就丢 | 短任务才用弹窗 |
| 路由切换加过渡动画 | 切页慢 | 直接切换 |
| 编辑页没有「保存」按钮 | 用户不知道当前是否已保存 | 「保存」按钮在右上角 |
| 锁定特定框架路由库 | 换框架就要重写 | URLSearchParams 是原生 API |
