# B04 · 面包屑组件实现

> 对应 A04 评分维度。**主 agent 落地实现**——给「左上角面包屑 + URL 双向同步 + 溢出折叠」的具体模式骨架。
> 加载本 ref 前必读 [[B00-实现总纲]] 与 [[A04-导航与面包屑评分]]。
>
> **本 ref 讲思想与模式，不绑定特定框架**。

## 实现目标

把 [[A04-导航与面包屑评分]] 要求的**左上角 + 三层覆盖 + URL 双向同步 + 溢出折叠**落地为可复用的面包屑组件。

## 模式骨架

```
结构：
  ┌─ breadcrumb (height: 32px, white-space: nowrap) ────────────────┐
  │  seg1  >  seg2  >  seg3  >  seg4(current)                         │
  └──────────────────────────────────────────────────────────────────┘

每段渲染规则：
  - 当前段：<span> + 文字 + 字重 600 + cursor: default（不可点击）
  - 非当前段：链接 + hover 时变色 + 下划线（可点击，跳回对应层）
  - 分隔符：> （不用 /，避免与路径混淆）

溢出折叠：
  - 段数 ≤ 4：全部展示
  - 段数 > 4：保留首段 + 末段，中间折叠为 …
  - hover … 时弹出完整路径
  - 永远不换行（white-space: nowrap）

URL 双向同步：
  - 路径变化时自动更新 segments
  - 段点击时更新 URL（pushState 加历史栈）
  - 浏览器前进 / 后退正确反映
```

### 三层覆盖

```
列表页：  模块名 > 分组路径（最后一段不可点击）
详情页：  模块名 > 分组路径 > 资源名（资源名不可点击）
编辑页：  同详情页
```

## 关键 props / state（框架无关）

| 概念 | 形态 | 说明 |
| --- | --- | --- |
| Breadcrumb 输入 | `segments: [{ label, to? }]` | `to` 缺省 = 当前段不可点击 |
| 内部状态 | `showFull: boolean` (hover 弹出完整路径) | 溢出时折叠 |
| URL 双向同步 | `useUrlSync` 或框架路由 API | 视图状态 ↔ URL |

## 框架映射（任意框架适用）

| 概念 | 实现要点 |
| --- | --- |
| 链接渲染 | 用框架的链接组件（`<a>` / `<Link>` / `<router-link>`），目标 `to` 缺省时渲染 `<span>` |
| URL 同步 | 用框架路由 API 或 `URLSearchParams` + `history.pushState` |
| 溢出折叠 | 段数判断 + hover 弹出 popup（任意 UI 栈都支持） |

## 测试要点

- [ ] 面包屑在左上角（DOM 检查）
- [ ] 列表页 / 详情页 / 编辑页都有面包屑
- [ ] 当前段不可点击（`<span>` 而非链接）
- [ ] 非当前段可点击且跳回对应层
- [ ] URL 与面包屑双向同步（刷新 / 后退可用）
- [ ] 路径 > 4 段时折叠为 …，hover 弹出
- [ ] 面包屑高度固定 32px
- [ ] 不用 emoji，分隔符 >

## 反模式

| 错误做法 | 后果 | 正确做法 |
| --- | --- | --- |
| 面包屑放右上角 | 路径感丢失 | TopBar.left |
| 当前段用链接 | 点自己名导致状态错乱 | 当前段 <span> 无 to |
| 面包屑与 URL 不同步 | 后退时面包屑不动 | URL 同步 hook |
| 用 / 做分隔符 | 与路径混淆 | > |
| 面包屑换行 | 顶部栏高度跳来跳去 | white-space: nowrap + 折叠 |
| 面包屑里用 emoji | 跨平台渲染不一致 | 不带 |
| 路径过长不折叠 | 顶部栏被挤高 | 段数 > 4 折叠 |
| 锁定框架 Link 组件 | 换框架就要重写 | 用原生 <a> + pushState 即可 |
