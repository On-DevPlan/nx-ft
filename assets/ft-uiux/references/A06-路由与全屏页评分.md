# A06 · 路由与全屏页评分标准

> sub-agent 评分用。**不写代码、不讲怎么做**——只给**与本项目审美基准的匹配度评分**。
> 本项目的审美基准：**弹窗只承担短任务，复杂操作开路由全屏页 + URL 状态落地**。
> 加载本 ref 前必读 [[A00-审核总纲]]。

## 评分目标

评估面板的**路由与全屏页使用**与本项目审美基准的匹配度——弹窗 vs 全屏页的判定、URL 状态同步、编辑页布局。

## 评分维度（每项 0-5）

### 1. 弹窗 vs 全屏页判定匹配度（权重 2）
- 多风格对比 / 大预览 / 多栏编辑是否开路由
- 删除确认 / 短提示 / 错误反馈是否用弹窗

### 2. 三层路由覆盖度（权重 2）
- 列表 / 分组 / 详情 / 编辑是否都有独立路由

### 3. URL 状态同步度（权重 2）
- 视图状态（搜索 / 标签 / 排序 / 分页 / 已选）是否全部落到 URL
- 浏览器前进 / 后退 / 分享链接是否可复现

### 4. 编辑页布局匹配度（权重 1）
- 是否有三栏（元信息 / 代码 / 预览）+ 可拖拽分隔条
- 风格切换 / 新风格 / 保存按钮是否在右上角固定位置

## 评分标准（绝对严格）

### S 级（5 分）
- 弹窗 vs 全屏判定清晰、三层路由覆盖、URL 状态全落地
- 编辑页三栏布局 + 可拖拽分隔条
- **完全匹配本项目审美基准**

### A 级（4 分）
- 满足 S 级全部条件，仅小缺（如 URL 状态少一个）
- **整体匹配**

### B 级（3 分）
- 弹窗 / 全屏判定基本合理，但 URL 同步不全
- **基本匹配**

### C 级（2 分，必须修复）
- 视图状态只放内存（刷新就丢）
- 编辑页用一栏布局（编辑 + 预览上下叠）
- **明显偏离**

### D 级（1 分，拒绝通过）
- 弹窗里塞大预览 / 多风格对比 / 表单
- **完全背离本项目审美基准**

### F 级（0 分，拒绝通过）
- 没有路由，弹窗里塞一切
- **用户体验崩坏**

## 评分依据（命中即扣分）

| 偏离项 | 扣分依据 |
| --- | --- |
| 详情 / 编辑塞进 modal | modal 里塞大预览、塞多风格对比 |
| 视图状态只放内存 | 刷新就丢、不能分享链接 |
| 编辑页用一栏布局 | 预览要拉到底才能看 |
| 弹窗里有「保存」按钮 | 关掉弹窗就丢 |
| 路由切换加过渡动画 | 切页慢、用户烦躁 |
| 编辑页没有「保存」按钮（自动保存） | 用户不知道当前是否已保存 |
| 路径 4 段以上不折叠 | 顶部栏被挤高 |
| 没有详情页路由 | 用户只能用弹窗看详情 |
| 没有分组页路由 | 所有资源堆在根列表 |
| 弹窗里有「保存」按钮 + 表单字段 | 关掉弹窗就丢 |

## 评分报告模板

参见 [[A00-审核总纲]]「输出报告模板」一节，按以下顺序输出：

1. 与本项目审美基准的匹配度
2. 弹窗 vs 全屏页判定匹配度评分
3. 三层路由覆盖度评分
4. URL 状态同步度评分
5. 编辑页布局匹配度评分
6. 垃圾 UI/UX 命中清单
7. 总分、结论

## 评分 SOP（sub-agent 工作流）

1. 加载本 ref（A06）确定评分维度
2. 打开目标模块的 view.jsx + 路由配置
3. 与本项目审美基准做**对照评分**：
   - 弹窗里塞了什么？是短任务还是复杂操作？
   - 路由层数：列表 / 分组 / 详情 / 编辑都有？
   - URL 参数：搜索 / 标签 / 排序 / 分页 / 已选是否齐？
   - 编辑页布局：三栏 + 可拖拽分隔条？
4. 按评分标准套等级
5. 输出报告
