# A01 · 配色与视觉密度评分标准

> sub-agent 评分用。**不写代码、不讲怎么做**——只给**与本项目审美基准的匹配度评分**。
> 本项目的审美基准：**GitHub 仓库页**——一个主色点睛、灰阶为主、无装饰。
> 加载本 ref 前必读 [[A00-审核总纲]]。

## 评分目标

评估面板在配色与视觉密度上**与 GitHub 仓库页的匹配度**。
**匹配 = 高分，偏离 = 低分，垃圾 = F**。

## 评分维度（每项 0-5）

### 1. 主色克制度（权重 2）
- 是否仅一个主色 `#2da44e`（绿色），且仅用于主操作 / 选中态 / 成功文字

### 2. 危险色克制度（权重 1）
- 危险操作是否仅用 `#cf222e` outline 按钮（不做大色块）

### 3. 字号层级匹配度（权重 1）
- 是否只有 11 / 12 / 14 三档（与 GitHub 仓库页一致）

### 4. 密度匹配度（权重 1）
- 行高是否 28px、按钮 / 输入框高度是否 32px（与 GitHub 仓库页一致）

### 5. 分隔匹配度（权重 1）
- 是否用 1px 浅底线（`#d0d7de`）分隔（与 GitHub 仓库页一致）

## 评分标准（绝对严格）

### S 级（5 分）
- 主色仅 `#2da44e` 一处；危险色仅 `#cf222e` outline；状态用文字 + 图标表达
- 字号严格 11 / 12 / 14 三档；行高 28px；按钮 32px
- 1px 浅底线分隔，无背景色块分组
- **完全匹配 GitHub 仓库页审美**

### A 级（4 分）
- 满足 S 级全部条件，但某处微调（如 13px 字号但极少处使用）
- **整体匹配，仅极小偏离**

### B 级（3 分）
- 主色仅一处，但某状态仍用彩色区分（如警告用黄色块）
- **基本匹配，但偏离了「克制」原则**

### C 级（2 分，必须修复）
- 主色 4+ 处；或给不同状态发散彩色（成功绿失败红警告黄待办蓝）
- 字号 11 / 13 / 15 / 18 混用
- **明显偏离本项目审美**

### D 级（1 分，拒绝通过）
- 大面积彩色背景 / 渐变 / 阴影装饰
- **完全背离 GitHub 仓库页的克制风格**

### F 级（0 分，拒绝通过）
- 彩虹配色（5+ 颜色同时出现在一个视图）
- **视觉污染**

## 评分依据（命中即扣分）

| 偏离项 | 扣分依据 |
| --- | --- |
| 顶部 banner 用品牌色大色块 | 与克制原则直接冲突 |
| 卡片背景用蓝 / 绿 / 黄 | 卡片只能用白 / 浅灰 |
| 状态用颜色区分（成功绿、失败红、警告黄、待办蓝） | 颜色爆炸 |
| 渐变背景（`linear-gradient`） | 与克制风格冲突 |
| 阴影装饰（`box-shadow: 0 4px 12px`） | 让页面变花 |
| emoji 当图标或装饰 | 跨平台渲染不一致 |
| 字号 11/13/15/18 混用 | 字号跳跃 |
| 行间距 6/10/14/20 混用 | 间距档位过多 |
| 彩色分隔线（红 / 绿） | 一律灰 |
| 危险操作做大色块（红色实心按钮） | 危险操作必须 outline |
| 字号只有一档（全部 14px） | 层级不足 |

## 评分报告模板

参见 [[A00-审核总纲]]「输出报告模板」一节，按以下顺序输出：

1. 与 GitHub 仓库页审美基准的匹配度（含具体匹配项 / 偏离项）
2. 主色克制度评分
3. 危险色克制度评分
4. 字号层级匹配度评分
5. 密度匹配度评分
6. 分隔匹配度评分
7. 垃圾 UI/UX 命中清单（按 D/F/C 分组）
8. 总分 = 加权平均，套 S/A/B/C/D/F
9. 结论：通过 / 阻塞 / 拒绝通过

## 评分 SOP（sub-agent 工作流）

1. 加载本 ref（A01）确定评分维度
2. 打开目标文件 / 截图
3. 与 GitHub 仓库页做**对照评分**（不是凭感觉打分）：
   - 颜色数量：取所有 `#[0-9a-f]{6}` 值，应只有 8 个标准色
   - 字号档位：取所有 `font-size` 值，应只有 11 / 12 / 14
   - 状态区分方式：是否用颜色（是 → C）
   - 装饰：渐变 / 阴影 / 彩色块 → 命中即 D
   - emoji：正则 `[\u{1F300}-\u{1FAFF}]` → 命中即 D
4. 按评分标准套等级
5. 输出报告
