# B03 · CRUD 表单与列表实现

> 对应 A03 评分维度。**主 agent 落地实现**——给「完整 CRUD + 查询入口 + URL 同步」的具体模式骨架。
> 加载本 ref 前必读 [[B00-实现总纲]] 与 [[A03-CRUD完备性评分]]。
>
> **本 ref 讲思想与模式，不绑定特定框架**。

## 实现目标

把 [[A03-CRUD完备性评分]] 要求的**五端点 + 查询入口 + URL 同步 + 表单校验 + 删除确认**落地为可复用的表单与列表模式。

## 模式骨架

### 列表 + 查询入口（视图状态全部落到 URL）

```
视图状态：
  q          关键字搜索（匹配 名 / 展示名 / 路径 / 标签 / 风格名）
  tags       标签筛选（多选 AND，逗号分隔）
  sort       排序（默认 updatedAt:desc）
  page       分页（100+ 资源强制分页）
  batch      已选集合 id 列表（批量模式）

URL 同步规则：
  - 视图状态全部从 URL 读（页面加载时）
  - 任何状态变更都写回 URL（用 replaceState 不污染历史栈）
  - 浏览器后退 / 刷新 / 分享链接全部可复现同状态

列表区：
  - 顶部工具栏：搜索框 / 标签筛选 / 排序下拉 / 分页器
  - 主体：勾选 + 主标识 + 元信息 + 操作
  - 每行严格 28px（详见 [[B02-布局与分隔条实现]]）
```

### 表单（create + update 复用）

```
校验规则（前端）：
  - 必填项必填（提交前客户端校验）
  - 重复名给警告（不是拦截）—— 让用户决策
  - 非法字符给提示（不要等服务端 400）

表单字段：
  - name        资源名（必填，校验：仅字母/数字/连字符）
  - label       展示名（可选）
  - tags        标签（逗号分隔，提交时归一化）
  - style       风格名（默认 'default'）

提交流程：
  - 校验失败：弹错误提示（不静默）
  - 提交过程：按钮 loading 态 + 禁用防重复
  - 成功：跳转到详情页 + toast 反馈
  - 失败：弹错误提示（带原因）
```

### 删除（二次确认）

```
最小实现：
  - 弹出确认条（含资源名 + 「此操作不可撤销」）
  - [确认删除] [取消]

非空资源（带风格 / 带子资源）：
  - 明确告知影响范围（数量 + 资源名）
  - 强制输入校验（如输入 DELETE 才可确认）
  - 服务端先返回 blocked 状态让上层决策
```

## 关键 props / state（框架无关）

| 组件 | 关键 prop / state | 说明 |
| --- | --- | --- |
| List | URL params（q / tags / sort / page） | 视图状态全部从 URL 读 |
| Toolbar | q / tags / sort + 变更回调 | 任何变更都写回 URL |
| Form | initial / onSubmit | create / update 复用 |
| DeleteConfirm | resource / onConfirm / onCancel | 非空资源强制输入校验 |

## 框架映射（任意框架适用）

| 概念 | 实现要点 |
| --- | --- |
| URL ↔ state 同步 | 用 `URLSearchParams`（浏览器原生 API，任何框架都能用） |
| 表单校验 | 客户端 `validate()` 函数 + 服务端再校验一次 |
| 提交 loading 态 | `disabled` + 文本切换（"保存" → "保存中…"） |
| 删除确认 | 弹窗 / inline 确认条（短任务） |

- [ ] 五端点全部可调用（create / read / update / delete + list）
- [ ] 关键字搜索、标签筛选、排序、分页全部生效

## 反模式

| 错误做法 | 后果 | 正确做法 |
| --- | --- | --- |
| 视图状态只放内存 | 刷新就丢 | 全部落到 URL（URLSearchParams） |
| 删除无二次确认 | 误删无法挽回 | DeleteConfirm + 输入校验 |
| 必填项无校验 | 服务端兜底 | validate() + required |
| 表单提交后不跳转 | 用户不知道发生了什么 | 路由跳转 + toast |
| 列表只展示名 + 一个字段 | 其余字段浪费 | 全部展示 |
| 重复名不警告直接提交 | 用户操作无反馈 | 重复名给警告 |
| 锁定框架特定 hook | 换框架就要重写 | URLSearchParams 是浏览器原生 |
