# B01 · 配色变量与主题实现

> 对应 A01 评分维度。**主 agent 落地实现**——给「配色克制 / 视觉密度」的具体模式骨架。
> 加载本 ref 前必读 [[B00-实现总纲]] 与 [[A01-配色与密度评分]]。
>
> **本 ref 讲思想与模式，不绑定特定框架**——
> 任何支持 CSS 变量 + 主题切换的栈都能套用。

## 实现目标

把 [[A01-配色与密度评分]] 要求的**配色克制 + 视觉密度匹配 GitHub 仓库页**落地为可切换的样式系统。

## 模式骨架

### 8 色色板（核心）

```
--color-primary    主色：主操作按钮 / 选中态 / 成功文字  #2da44e
--color-danger     危险：仅 outline 按钮 + 错误文字      #cf222e
--color-link       链接：可点击文字                       #0969da
--color-text       主文字                                #24292f
--color-text-muted 次要文字                              #57606a
--color-bg-subtle  浅底：行 hover / 分组容器              #f6f8fa
--color-border     浅线：分隔 / 边框                      #d0d7de
--color-bg         主体底                                #ffffff
```

**关键约束**：
- 全局只允许这 8 个颜色字面量出现，其他场景一律 `var(--...)`
- 主色 / 危险色 / 链接色在浅色 / 深色主题下**保持不变**（跨主题一致）
- 主体底 / 文字 / 浅线在浅色 / 深色主题下做映射

### 字号三档

```
--font-size-xs  元信息  11px
--font-size-sm  主体    12px
--font-size-md  标题    14px
```

**关键约束**：不允许 13 / 15 / 16 / 18 等中间档——层级差靠三档撑。

### 密度双层

```
--row-height    列表行高       28px
--btn-height    按钮高         32px
--input-height  输入框高       32px
--gap-sm        行内间距       4px
--gap-md        区块间距       8px
```

**关键约束**：不允许 36 / 40 / 44 等中间值——密度双层就是双层。

### 主题切换（伪代码）

```
初始化：
  theme = 从持久化存储读（localStorage / cookie / 服务端）
         默认 'light'

切换时：
  在根元素上设 data-theme="light" | "dark"
  持久化新值
  CSS 变量自动根据 [data-theme] 选择器切换映射
```

```
[data-theme="dark"]:
  --color-text       #e6edf3
  --color-text-muted #8b949e
  --color-bg-subtle  #15191f
  --color-border     #30363d
  --color-bg         #1f2328
  /* 主色 / 危险色 / 链接色跨主题不变 */
```

## 关键 props / state（框架无关）

| 元素 | 形态 | 用途 |
| --- | --- | --- |
| 主操作按钮 | 绿色实心（`var(--color-primary)`） | 主操作 |
| 危险按钮 | outline（`var(--color-danger)` 边 + 白底） | 删除 / 撤销 |
| 链接 | `var(--color-link)` | 可点击文字 |
| 列表行 | `height: var(--row-height)` | 列表 |
| 按钮 | `height: var(--btn-height)` | 按钮 |
| 输入框 | `height: var(--input-height)` | 输入框 |

## 与 A 评分标准的对照表（反向验证）

| A01 评分维度 | B01 落地手段 | 验证 |
| --- | --- | --- |
| 主色克制度 | 唯一 `var(--color-primary)` + 仅用于主操作 | grep `#[0-9a-f]{6}` 应只有 8 个 |
| 危险色克制度 | 唯一 `var(--color-danger)` + 仅用于 outline | grep 危险按钮应是 outline |
| 字号层级匹配度 | 三档 `--font-size-{xs,sm,md}` | grep `font-size` 应只有 11/12/14 |
| 密度匹配度 | `--row-height: 28px` `--btn-height: 32px` | grep `height:` 应只有 28/32 |
| 分隔匹配度 | `1px solid var(--color-border)` | grep 分隔线应一致 |

## 测试要点

- [ ] 浅色 / 深色主题下颜色映射正确
- [ ] 主色 / 危险色 / 链接色跨主题不变
- [ ] 字号严格 11 / 12 / 14 三档
- [ ] 行高 28px、按钮 32px、输入框 32px
- [ ] 分隔线统一 `1px solid var(--color-border)`
- [ ] 无 emoji（grep `[\u{1F300}-\u{1FAFF}]` 为空）

## 反模式

| 错误做法 | 后果 | 正确做法 |
| --- | --- | --- |
| 直接写颜色字面量 `#2da44e` | 主题切换失效 | 用 `var(--color-primary)` |
| 给不同状态发散彩色 | 颜色爆炸 | 状态用文字 + 图标 |
| 加渐变 / 阴影 | 与克制风格冲突 | 不加 |
| 字号 11/13/15/18 混用 | 字号跳跃 | 只用三档 |
| emoji 当图标 | 跨平台渲染不一致 | SVG 图标（[[B08]]） |
| 锁定 React | 换框架就要重写 | CSS 变量是底层契约 |
