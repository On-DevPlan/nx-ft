# A04 · 导航路径与面包屑评分标准

> sub-agent 评分用。**不写代码、不讲怎么做**——只给**与本项目审美基准的匹配度评分**。
> 本项目的审美基准：**面包屑永远在左上角 + 三层覆盖 + URL 双向同步**。
> 加载本 ref 前必读 [[A00-审核总纲]]。

## 评分目标

评估面板的**导航路径感**与本项目审美基准的匹配度——用户进深层后不会迷路。

## 评分维度（每项 0-5）

### 1. 面包屑位置匹配度（权重 3）
- 是否永远在左上角（不是右、不是底部、不是无）

### 2. 面包屑完整性匹配度（权重 2）
- 列表页 / 详情页 / 编辑页是否有面包屑
- 分组路径 ≥ 2 段时是否完整展示

### 3. 可点击性匹配度（权重 2）
- 当前段是否不可点击
- 非当前段是否可点击且跳回对应层

### 4. URL 双向同步匹配度（权重 2）
- 浏览器前进 / 后退是否正确反映在面包屑
- 面包屑点击跳转是否正确反映在 URL

### 5. 溢出处理匹配度（权重 1）
- 路径过长时是否折叠为 `…` + hover 弹出
- 是否避免换行

## 评分标准（绝对严格）

### S 级（5 分）
- 面包屑永远在左上角；三层都有；可点击；双向同步；溢出折叠
- **完全匹配本项目审美基准**

### A 级（4 分）
- 满足 S 级全部条件，仅极小偏离
- **整体匹配**

### B 级（3 分）
- 面包屑位置正确但 URL 不同步
- **基本匹配，但偏离了「双向同步」原则**

### C 级（2 分，必须修复）
- 详情页 / 编辑页缺面包屑
- 当前段可点击
- **明显偏离**

### D 级（1 分，拒绝通过）
- 面包屑放右上角 / 底部
- **完全背离本项目审美基准**

### F 级（0 分，拒绝通过）
- 没有面包屑（多层资源）
- **用户进深层后无路可退**

## 评分依据（命中即扣分）

| 偏离项 | 扣分依据 |
| --- | --- |
| 没有面包屑（树形 / 多层资源） | 用户进深层后无路可退 |
| 面包屑放右上角 | 用户进深层后找不到回去的路 |
| 面包屑放底部 | 与扫视习惯冲突 |
| 详情页没面包屑 | 用户只能用浏览器后退 |
| 编辑页没面包屑 | 同上 |
| 当前段可点击 | 点自己名导致状态错乱 |
| 面包屑与 URL 不同步 | 后退时面包屑不动 |
| 用 `/` 做分隔符 | 与路径混淆 |
| 面包屑换行 | 顶部栏高度跳来跳去 |
| 面包屑里用 emoji | 跨平台渲染不一致 |
| 路径过长不折叠 | 顶部栏被挤高 |
| 面包屑不可点击（纯文字） | 失去导航功能 |

## 评分报告模板

参见 [[A00-审核总纲]]「输出报告模板」一节，按以下顺序输出：

1. 与本项目审美基准的匹配度
2. 面包屑位置匹配度评分
3. 面包屑完整性匹配度评分
4. 可点击性匹配度评分
5. URL 双向同步匹配度评分
6. 溢出处理匹配度评分
7. 垃圾 UI/UX 命中清单
8. 总分、结论

## 评分 SOP（sub-agent 工作流）

1. 加载本 ref（A04）确定评分维度
2. 打开目标模块的 view.jsx
3. 与本项目审美基准做**对照评分**：
   - 面包屑组件位置：`top: 0; left: 0`？还是别的位置？
   - 三层覆盖：列表 / 详情 / 编辑是否都有？
   - 当前段是否不响应？非当前段是否跳？
   - 浏览器前进 / 后退是否反映在面包屑？
   - 长路径是否折叠？
4. 按评分标准套等级
5. 输出报告
