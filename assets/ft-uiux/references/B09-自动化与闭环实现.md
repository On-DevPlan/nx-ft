# B09 · 自动化与闭环实现

> 对应 A09 评分维度。**主 agent 落地实现**——给「A 评分自动跑 + A→B→A 真闭环」的具体模式骨架。
> 加载本 ref 前必读 [[B00-实现总纲]] 与 [[A09-自动化与闭环评分]]。
>
> **本 ref 讲思想与模式，不绑定特定框架**——GitHub Actions / GitLab CI / Jenkins 都适用。

## 实现目标

把 [[A09-自动化与闭环评分]] 要求的**A 评分自动跑 + lint / e2e / no-emoji 自动跑 + A→B→A 真闭环 + 异常回流 + 可观测性**落地为可执行的流水线与脚本。

## 模式骨架

### 流水线骨架

```
触发时机：
  - push 到任何分支（PR 检查）
  - pull_request 开 / 同步（PR 检查）
  - 定时（每日 / 每周，可选）

步骤串联（按顺序）：
  1. checkout 代码
  2. 安装依赖
  3. 跑 lint（eslint）
  4. 跑 no-emoji 检查（scripts/check-no-emoji.mjs）
  5. 跑 A 评分脚本（scripts/score-uiux.mjs）
  6. 跑 e2e 真点验证（playwright / cypress）
  7. build（vite build）
  8. 上传结果（截图 / 报告 / 评分历史）

失败时：
  - 任何步骤失败 = 流水线失败 = PR 不可合入
  - 失败时上传日志 + 截图 + 评分报告
```

### A 评分脚本（核心）

```
输入：
  - 目标文件路径 / 模块名 / 组件名
  - 评分维度（A01~A09）
  - 项目审美基准（来自 A00）

输出：
  - 评分报告（结构化 JSON）
  - 截图（如适用）
  - 失败项列表（C/D/F）

关键点：
  - 必须是确定性脚本（不是 LLM 调用）—— 保证 CI 可重跑
  - 输出结构化 JSON（机器可读）
  - 退出码：0 = 通过 / 1 = 阻塞 / 2 = 拒绝
```

### A→B→A 闭环（主 agent 工作流）

```
正常流程：
  1. 主 agent 收到任务
  2. 调 sub-agent 跑 A 评分（前置）
  3. 主 agent 读 A 报告，列「需要做的 B 实现项」
  4. 主 agent 按 B01~B09 加载实现参考，写代码
  5. 主 agent 调 sub-agent 再跑 A 评分（验收）
  6. 通过 = 交付；不通过 = 回到第 4 步

自动化：
  - 第 2 步 + 第 5 步都通过 CI 触发（不靠主 agent 记得）
  - 不达标时自动创建 issue 标「阻塞」
  - 修复后自动重新触发 CI
```

### 异常回流

```
触发场景：
  - A 评分 C/D/F
  - e2e 失败
  - 用户在面板报错
  - lint 报错

回流方式：
  - 自动创建 issue（标题含评分维度 + 失败项）
  - 标 label（如 uiux-block / e2e-fail / lint-error）
  - 关联 PR（让修复可追踪）
  - 主 agent / sub-agent 在收到 issue 后自动介入
```

### 可观测性

```
存档内容：
  - A 评分历史（每次评分的时间 / 对象 / 维度 / 结果）
  - 截图（e2e 每次跑必拍）
  - 日志（CI 每次跑必存）
  - 报告（结构化 JSON）

存储方式：
  - artifacts（CI 内置）
  - 远端存储（S3 / GCS / OSS，可选）
  - 数据库（可选，但便于查询趋势）

查询方式：
  - 按时间 / 模块 / 评分维度
  - 看趋势（哪些维度反复出问题）
```

## 反模式

| 错误做法 | 后果 | 正确做法 |
| --- | --- | --- |
| 「我跑过一次 A 评分」就算自动化 | 改完代码后还得手工跑 | 纳入 CI 自动触发 |
| 失败时只警告不阻断 | 失败也能合入 | 必需检查 |
| B 写完没人回头 A | 闭环没回到 A | 主 agent SOP 强制回头 |
| 没存档 | 出问题无据可查 | 评分历史存档 |
| 异常无回流 | 用户报错丢了 | 失败 → 自动 issue |
| A 评分脚本是 LLM 调用 | 不可重跑 | 确定性脚本 |
| 流水线分支保护缺失 | 失败也能合入 | 必需检查 |
| 锁定单一 CI 系统 | 换 CI 就要重写 | 模式通用（任何 CI 都行） |
