# A02 · 布局与信息层级评分标准

> sub-agent 评分用。**不写代码、不讲怎么做**——只给**与本项目审美基准的匹配度评分**。
> 本项目的审美基准：**F 型扫视 + 面包屑左上角 + 留白撑层级**。
> 加载本 ref 前必读 [[A00-审核总纲]]。

## 评分目标

评估面板的**视觉重心、扫视路径、信息层级**与本项目审美基准的匹配度。

## 评分维度（每项 0-5）

### 1. 顶部栏布局匹配度（权重 2）
- 面包屑是否永远在左上角
- 搜索 / 批量 / 用户操作是否永远在右上角
- 模块名（图标 + 文字）位置是否合理

### 2. 主体分区匹配度（权重 2）
- 左右 / 上下分区是否清晰
- 分区之间是否有可拖拽分隔条

### 3. 信息层级匹配度（权重 1）
- 标题区 / 主体区 / 元信息区是否有视觉差异
- 是否用字号 / 字重 / 留白区分层级（而非用颜色）

### 4. 留白与分隔匹配度（权重 1）
- 分组内是否用留白撑层级
- 行间是否用 1px 浅底线分隔
- 是否避免了大色块做分组

### 5. 列表扫视路径匹配度（权重 1）
- 列表行高 28px 是否一致
- 行内元素顺序是否符合扫视习惯（勾选 → 主标识 → 元信息 → 操作）

## 评分标准（绝对严格）

### S 级（5 分）
- 顶部栏布局完全符合 F 型扫视（面包屑左上、操作右上）
- 主体分区清晰，栏间有可拖拽分隔条
- 信息层级靠字号 / 字重 / 留白，不用颜色
- 行高 28px 一致，行内元素顺序符合扫视习惯
- **完全匹配本项目审美基准**

### A 级（4 分）
- 满足 S 级全部条件，仅极小偏离
- **整体匹配**

### B 级（3 分）
- 主体分区不清晰，或缺少分隔条
- 信息层级稍弱
- **基本匹配，但有明显改进空间**

### C 级（2 分，必须修复）
- 信息层级靠颜色区分（非字号 / 字重）
- 行高不一致
- 行内元素顺序错乱
- **明显偏离**

### D 级（1 分，拒绝通过）
- 面包屑不在左上角
- 大色块做分组
- 顶部栏元素位置错乱（面包屑在右、搜索在左）
- **完全背离本项目审美基准**

### F 级（0 分，拒绝通过）
- 没有视觉重心、信息全堆在一起
- **视觉混乱**

## 评分依据（命中即扣分）

| 偏离项 | 扣分依据 |
| --- | --- |
| 面包屑放右上角 | 路径感丢失 |
| 顶部栏左边空白、右边堆满 | 重心错乱 |
| 卡片背景色五彩斑斓 | 卡片只能用白 / 浅灰 |
| 用大色块做分组（不同卡片不同背景色） | 与克制风格冲突 |
| 信息层级靠颜色（标题红、正文蓝） | 颜色不该承担层级 |
| 行高不一致（有的 28、有的 36、有的 44） | 视觉跳动 |
| 行内元素顺序错乱（操作在左、勾选在右） | 违反扫视习惯 |
| 卡片宽度固定、不能改 | 违反可拖拽原则 |
| 标题区用比正文大 1px 的字号（13 vs 12） | 层级差不够 |
| 列表行高 36px 或更大 | 太松散 |
| 没有主体分区，所有内容塞一栏 | 信息密度低 |

## 评分报告模板

参见 [[A00-审核总纲]]「输出报告模板」一节，按以下顺序输出：

1. 与本项目审美基准的匹配度（含具体匹配项 / 偏离项）
2. 顶部栏布局匹配度评分
3. 主体分区匹配度评分
4. 信息层级匹配度评分
5. 留白与分隔匹配度评分
6. 列表扫视路径匹配度评分
7. 垃圾 UI/UX 命中清单
8. 总分、结论

## 评分 SOP（sub-agent 工作流）

1. 加载本 ref（A02）确定评分维度
2. 打开目标文件 / 截图
3. 与本项目审美基准做**对照评分**：
   - 面包屑位置：左上角？右？底部？无？
   - 主体分区：左/中/右？上/下？无分区？
   - 行高一致性：抽 5 行量行高
   - 行内元素顺序：抽 3 行看顺序
   - 层级区分方式：字号 / 字重 / 颜色？
4. 按评分标准套等级
5. 输出报告
