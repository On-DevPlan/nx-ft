# B02 · 布局与分隔条实现

> 对应 A02 评分维度。**主 agent 落地实现**——给「布局匹配 F 型扫视 + 可拖拽分隔条」的具体模式骨架。
> 加载本 ref 前必读 [[B00-实现总纲]] 与 [[A02-布局与层级评分]]。
>
> **本 ref 讲思想与模式，不绑定特定框架**。

## 实现目标

把 [[A02-布局与层级评分]] 要求的**F 型扫视 + 面包屑左上角 + 留白撑层级 + 可拖拽分隔条**落地为可复用的布局原语。

## 模式骨架

### 顶部栏三段布局

```
结构：
  ┌─ topbar (height: 40px, border-bottom: 1px) ─────────────────────┐
  │  ┌─ topbar-left ────────────────┐  ┌─ topbar-right ──────────┐   │
  │  │  breadcrumb + moduleName     │  │  search + actions       │   │
  │  └──────────────────────────────┘  └─────────────────────────┘   │
  └──────────────────────────────────────────────────────────────────┘

关键约束：
  - 面包屑永远在 topbar-left
  - 搜索 / 批量 / 用户操作永远在 topbar-right
  - 模块名（图标 + 文字）在 topbar-left 的面包屑右侧
  - topbar 高度固定，不被面包屑撑高
```

### 主体可拖拽分隔条布局

```
结构：
  ┌─ split-container (display: flex) ──────────────────────────────┐
  │  ┌─ split-pane-left ──┐ ┌─ split-divider ┐ ┌─ split-pane-right ┐│
  │  │                     │ │  (4px 可拖拽)  │ │                   ││
  │  └─────────────────────┘ └────────────────┘ └───────────────────┘│
  └─────────────────────────────────────────────────────────────────┘

拖拽逻辑：
  - 记录鼠标按下状态
  - mousemove 时按比例更新 left / right 宽度
  - 受 min / max 比例约束（避免拖到看不见）
  - mouseup 时清除状态

约束：
  - minPct = 15%（左侧不能小于 15%）
  - maxPct = 60%（左侧不能大于 60%）
  - 分隔条 hover 时颜色变深（视觉反馈）
  - 拖拽过程整页不卡顿
```

### 列表行（行高 28px + 行内顺序）

```
结构：
  ┌─ list-row (height: 28px) ──────────────────────────────────────────┐
  │  [check]  primary                secondary          actions         │
  │  (28px)   (1fr)                  (auto)             (auto)          │
  └────────────────────────────────────────────────────────────────────┘

行内顺序（关键）：勾选 → 主标识 → 元信息 → 操作
  - 违反这个顺序 = 违反扫视习惯

约束：
  - 行高严格 28px，不允许 32 / 36 / 44
  - 行内元素 grid 布局，gap 12px
  - hover 时背景色 var(--color-bg-subtle)
  - border-bottom: 1px solid var(--color-border)
```

## 关键 props / state（框架无关）

| 组件 | 关键 prop | 说明 |
| --- | --- | --- |
| TopBar | breadcrumb / moduleName / searchSlot / actionsSlot | slot 设计保证左右职责清晰 |
| SplitPane | left / right / initialLeftPct / minPct / maxPct | 比例受 min/max 约束 |
| ListRow | checked / onCheck / primary / secondary / actions | 行内顺序固定 |

## 框架映射（任意框架适用）

| 概念 | 实现要点 |
| --- | --- |
| TopBar | 任何容器 + flex 布局都能实现；slot 用 children / props 传 |
| SplitPane | 核心是 mousemove 监听 + 比例更新；React 用 state、Vue 用 ref、Svelte 用 store |
| ListRow | grid 布局 + 固定行高；任意 UI 栈都支持 |

## 测试要点

- [ ] 顶部栏左边是面包屑+模块名，右边是搜索+操作
- [ ] 拖拽分隔条时左右宽度变化，受 min/max 约束
- [ ] 列表行严格 28px，行内顺序为 check → primary → secondary → actions
- [ ] 信息层级靠字号 / 字重，不用颜色
- [ ] 分隔线统一 1px solid var(--color-border)
- [ ] 无大色块分组

## 反模式

| 错误做法 | 后果 | 正确做法 |
| --- | --- | --- |
| 面包屑放右上角 | 路径感丢失 | TopBar.left |
| 卡片宽度固定 | 用户无法调整 | SplitPane 提供可拖拽分隔条 |
| 行内顺序错乱 | 违反扫视习惯 | check → primary → secondary → actions |
| 用颜色做层级 | 颜色承担层级 | 用字号 / 字重 |
| 大色块做分组 | 与克制风格冲突 | 用留白 + 1px 浅底线 |
| 锁定 React Hooks | 换框架就要重写 | 用 mousemove 原生事件即可 |
