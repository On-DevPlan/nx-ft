# B08 · 图标与一致性实现

> 对应 A08 评分维度。**主 agent 落地实现**——给「SVG 图标 + 无 emoji + 跨模块一致」的具体模式骨架。
> 加载本 ref 前必读 [[B00-实现总纲]] 与 [[A08-一致性与无emoji评分]]。
>
> **本 ref 讲思想与模式，不绑定特定框架**——任何 UI 栈都能落地。

## 实现目标

把 [[A08-一致性与无emoji评分]] 要求的**图标走 SVG + 无 emoji + 跨模块一致 + 跨主题一致**落地为共享组件库。

## 模式骨架

### SVG 图标组件（统一封装）

```
属性：
  name    string          图标名（必须在图标集字典里）
  size    number = 16     图标尺寸（px）
  其余属性透传            class / style / aria-* 等

规范（来自 ft-svg）：
  viewBox="0 0 24 24"    全组共享同一套坐标
  fill="none"            线性档不填色
  stroke="currentColor"  唯一允许的颜色用法，主题切换自动跟随
  stroke-width="1.8"     24pt 网格下的标准线宽
  stroke-linecap/linejoin="round"  圆端点
  width/height 不写      尺寸由 size 控制

图标集字典（PATHS）：
  每个图标一条 path d，参考 ../ft-svg/ 的完整图标集
  本组件只暴露 PATHS 的子集（项目实际用到的）
```

### 状态标签（无 emoji）

```
状态 → { 文字, 图标 } 映射：
  success   已完成    check
  error     失败      x
  warning   注意      warning
  loading   进行中    loading
  pending   待办      circle
  disabled  禁用      minus

渲染规则：
  - 文字永远在场（颜色只是辅助，无障碍场景不丢信息）
  - 图标走 SVG（不用 emoji）
  - 颜色用 var(--color-...)，跨主题一致
```

### 跨模块统一按钮

```
共享 Button 组件（所有模块共用）：
  variant: 'default' | 'primary' | 'danger' | 'link'
  icon:    string (SVG 图标名)
  children: 按钮文案

约束：
  - 所有模块用同一个 Button
  - 「+ 新建」「编辑」「删除」等高频按钮跨模块长得一致
  - variant 视觉用 [[B01-配色变量与主题实现]] 的 8 色色板
```

### 无 emoji 检测（CI 自动化）

```
检查脚本（跑在 lint 之后、build 之前）：
  - 遍历 src/web 下所有源文件
  - 正则匹配 emoji 字符范围
  - 命中即报错（exit 1）

关键 emoji 范围（参考 Unicode）：
  [\u{1F300}-\u{1FAFF}]    装饰符号 / 表情
  [\u{2600}-\u{27BF}]      杂项符号 / 几何形状（含 ⚠ ✓ ✗ 等）
  完整正则覆盖更稳，但核心是这两个范围

纳入 CI：
  - pnpm test:lint → check-no-emoji → build
  - 失败时阻断合入
```

## 关键 props / state（框架无关）

| 概念 | 形态 | 说明 |
| --- | --- | --- |
| Icon | name / size | name 必须在 PATHS 里，否则抛错 |
| StatusLabel | status / children | status 是 STATUSES 的 key |
| Button | variant / icon / children | 所有模块共用 |
| check-no-emoji | CI 脚本 | 自动检测 + 阻断 |

## 框架映射（任意框架适用）

| 概念 | 实现要点 |
| --- | --- |
| Icon | 任何 UI 栈都能渲染 SVG（`<svg>` 原生元素） |
| StatusLabel | 文字 + SVG 图标的组合组件 |
| Button | 共享样式（CSS 变量）+ 任意框架的按钮组件 |
| CI 脚本 | Node.js / Python / Bash 任选（核心是文件遍历 + 正则） |

## 反模式

| 错误做法 | 后果 | 正确做法 |
| --- | --- | --- |
| 直接写 emoji（✓ / ⚠） | 跨平台渲染不一致 | Icon + 文字 |
| 直接写 <img src="..."> | 没法用 currentColor | Icon 组件 |
| 每个模块自己写 Button | 视觉割裂 | 共享 Button |
| 状态用 emoji（🚧 / ❌） | 同上 | StatusLabel |
| 跨主题下图标写死颜色 | 主题切换失效 | currentColor |
| 没跑 check-no-emoji | emoji 偷偷混进 | CI 阻断 |
| 锁定单一框架的 icon 库 | 换框架就要重写 | SVG 是 W3C 标准 |
