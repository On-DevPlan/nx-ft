# B05 · 批量选择组件实现

> 对应 A05 评分维度。**主 agent 落地实现**——给「多选 / 全选 / 三态切换 / 跨页保留 / 危险确认」的具体模式骨架。
> 加载本 ref 前必读 [[B00-实现总纲]] 与 [[A05-批量操作评分]]。
>
> **本 ref 讲思想与模式，不绑定特定框架**。

## 实现目标

把 [[A05-批量操作评分]] 要求的**多选 + 全选 + 三态切换不崩 + 跨页保留 + 按钮永远在**落地为可复用的批量选择组件。

## 模式骨架

### 批量状态管理（核心）

```
状态：
  selected:    Set<id>           已选 id 集合（跨页保留）
  selectAllAcrossPages: bool     是否跨页全选
  visibleIds:  id[]              当前页可见 id（受分页 / 过滤影响）

操作：
  toggle(id)               切换单个
  selectAllVisible()       全选当前页
  selectAllAcross()        全选全部（跨页）
  deselectAll()            取消全选
  invertVisible()          反选当前页

关键不变量：
  - selected 不受 page / filter 影响（翻页后保留）
  - 退出批量模式时清空 selected
  - 切换过滤条件时给「清空已选」入口
  - selectAllAcrossPages = true 时，当前页全选 = 半选（indeterminate）
```

### 批量操作条 UI

```
结构：
  ┌─ batch-bar (height: 40px, role="toolbar") ─────────────────────┐
  │  [全选/取消]  [反选]  [取消批量]   |   已选 N 项   |   [批量 X]│
  └────────────────────────────────────────────────────────────────┘

按钮稳定性（关键）：
  - 按钮永远在（不根据已选数隐藏）
  - 已选 = 0 时「批量 X」disabled
  - 操作过程按钮 loading 态防重复提交
  - 操作完成后给结果反馈 + 自动清空已选
```

### 行勾选框

```
渲染规则：
  - 未选：空心方框
  - 已选：实心绿色方框 + 白色对勾
  - 半选（跨页全选 + 当前页已全选）：实心绿色方框 + 横线
  - 禁用：灰阶 + cursor: not-allowed
```

### 跨页保留（关键）

```
行为：
  1. 翻页：selected 不变（filter/page 变化不影响已选）
  2. 切换过滤条件：selected 不变（给「清空已选」入口）
  3. 退出批量模式：selected 清空
  4. 已选项超过当前过滤范围：给提示「已选项中有 N 项不在当前过滤结果内」
```

## 关键 props / state（框架无关）

| 概念 | 形态 | 说明 |
| --- | --- | --- |
| 状态管理 | `useBatchSelection(allIds)` hook / composable / store | 跨页保留 + 三态切换 |
| 批量条 | `BatchBar` 组件 | 5 按钮 + 计数 + 批量 X |
| 行勾选框 | `<input type="checkbox">` + indeterminate | 三态视觉 |

## 框架映射（任意框架适用）

| 概念 | 实现要点 |
| --- | --- |
| 状态管理 | React: hook / Vue: composable / Svelte: store / 纯 JS: module-level state |
| indeterminate | 原生 `<input>` 属性，任何 UI 栈都支持 |
| 跨页保留 | Set 不依赖具体框架，是 JS 原生数据结构 |

## 测试要点

- [ ] 全选 / 反选 / 取消 / 已选计数 / 批量 X 五项都在
- [ ] 三态切换时按钮永远在，不消失
- [ ] 翻页后已选项保留
- [ ] 切换过滤条件后已选项保留
- [ ] 退出批量模式后已选项清空
- [ ] 已选 = 0 时「批量删除」禁用
- [ ] 批量删除二次确认（非空资源输入 DELETE）
- [ ] 操作过程按钮加载态防重复提交
- [ ] 操作完成后已选集合自动清空

## 反模式

| 错误做法 | 后果 | 正确做法 |
| --- | --- | --- |
| 翻页后已选项全丢 | 用户选了几十项翻页全没了 | selected 不受 page 影响 |
| 「全选」= 只选当前页 | 选了几十项翻页就丢 | 给「全选全部 N 项」入口 |
| 按钮根据已选数隐藏 | 三态切换时按钮消失 | 按钮永远在，靠 disabled 控制 |
| 删除无确认 | 误删无法挽回 | DeleteConfirm |
| 退出后已选项残留 | 下次进入还显示已选 | 退出时 deselectAll |
| 操作过程可重复点击 | 重复提交 | loading 态 + disabled |
| 锁定框架特定 hook | 换框架就要重写 | Set 是 JS 原生 |
