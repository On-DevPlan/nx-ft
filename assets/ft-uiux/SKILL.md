# ft-uiux skill：UI/UX 视觉与交互规范

> 本 skill 是 nx-ft 项目所有 Web 面板的**审美层总约**。
> 它不分发命令——它规定「评什么、怎么评」（A 序列）与「怎么写」（B 序列）。
>
> **A 序列 = 评分（框架无关）；B 序列 = 实现（讲思想，不绑定框架）。**
> **A 评什么、B 给什么——编号一一对应。**

## 一句话

> **让 Web 面板像 GitHub 仓库页那样干净**——
> 一个主色点睛（`#2da44e`）、一处留白撑层级、一条灰线分块，
> 没有任何多余的纯色块与 emoji 装饰。

## SOP（主 agent 第一步：调 sub-agent 跑 A 评分）

收到「做 / 改 / 评审面板」任务时，**强制按下面 5 步走**：

| 步 | 谁来做 | 做什么 |
| --- | --- | --- |
| 1 | **主 agent** | 调 sub-agent 跑 [[A00-审核总纲]]，列出 A01~A09 评分维度 |
| 2 | **sub-agent** | 对每个 A 维度跑评分 SOP，输出报告（**不写代码**） |
| 3 | **主 agent** | 读 A 评分报告，列出「需要做的 B 实现项」（哪些 B 实现参考要加载） |
| 4 | **主 agent** | 按 B01~B09 加载对应实现参考，写代码 |
| 5 | **sub-agent** | **回头再跑一次 A 评分 SOP** —— 验证实现后是否真的达标 |

> **关键**：**A 评分 → B 实现 → A 评分**，这是「先评后做、再评验收」的**闭环**。
> - **不允许跳过 A 直接 B**（不知道差多少就动手，必然跑偏）
> - **不允许只 B 不回头 A**（写完必须再评一次，否则「达标」是自我安慰）
> - **A→B→A 闭环本身**也是 [[A09-自动化与闭环评分]] / [[B09-自动化与闭环实现]] 的评分对象——闭环断在哪一步，对应评回去。

详细 SOP 见 [[B00-实现总纲]]。

## 框架无关声明（B 系列）

**B 系列不绑定任何特定框架**——

- 任何现代 UI 栈（React / Vue / Svelte / 纯 HTML+CSS）都能套用
- 每个 B0X 末尾有「框架映射」表，给出 React / Vue / Svelte / 原生 HTML 的对应实现要点
- **核心契约是 CSS 变量 + 浏览器原生 API**（`URLSearchParams` / `history.pushState` / `<input type="checkbox">` / `<svg>` / `<dialog>`）—— 这些是 W3C 标准，跨框架稳定
- **不允许把 B 系列写成「React 专属」**——若用户后续切到 Vue / Svelte，B 系列不该废

> 项目当前用的是 React + Vite，但**未来的项目可能用别的框架**——重要的是**思想**，不是**当前栈的语法**。

## 何时**不**触发本 skill

- 用户要做**纯后端 / 数据层**工作 → 不涉及 UI/UX
- 用户要**改 skill 本身**的元数据 / 触发词 → 走 `key_board` 而非本 skill
- 用户要**给本项目某个模块做命令面**（CLI / API）→ 走脚手架 skill `server-cli-web-scaffold`

## 与其它 skill 的协作

```
key_board        →  skill 生命周期（路由 + 序列 ref 管理）
server-cli-web-scaffold →  脚手架（项目骨架、action 机制、状态、发布）
ft-svg           →  SVG 图标集规范（图标本体走它；本 skill B08 用）
ft-uiux (本)     →  UI/UX 视觉与交互规范
nx-ft            →  项目本身（CLI / API / 数据模型）
```

- **A 序列**评「UI/UX 与项目审美基准的匹配度」（框架无关，给任意框架的代码打通用分）
- **B 序列**给「落地模式骨架」（讲思想 + 框架映射，不锁定特定框架）
- B 序列实现参考里**所有图标**走 [[ft-svg]] 规范
- 本 skill **不重复**脚手架的命令面 / 数据模型约定——那些走 [[nx-ft]] 与脚手架

## 约束

- **B 系列讲思想，不绑定特定框架**——任何现代 UI 栈都能套用
- **A→B→A 闭环不可跳过**：先评后做、再评验收；闭环本身也受 [[A09-自动化与闭环评分]] 监督
