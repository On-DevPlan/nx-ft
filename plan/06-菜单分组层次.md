# 06 目录树菜单分组层次（P1）

来源：KV nx-rh localtask id=13「目录树的功能工作菜单分一下层次」。

右键菜单现在一项一项平铺（目录行 8 项、资源行 4 项），功能不同的操作混在一起，
扫读成本高。本次按**功能簇**用分隔符分组，让菜单有层次：导航 / 创建 / 数据交换 /
位置（系统）/ 编辑 / 危险。

主战场：
- 菜单渲染：`components/sidebar/row-menu.jsx`（RowMenu，目前不支持分隔符）
- 菜单定义：`components/asset/side-tree.jsx` 的 `rowMenu`
- 样式：`styles/sidebar.css`（`.gmenu` / `.gmenu-item`）

## 现状（已核实）

- RowMenu 把 `items` 全部渲染成 `button.gmenu-item`，items 形如
  `[{label, icon?, danger?, run}]`——**没有分隔符 / 分组概念**。
- 目录行菜单（8 项，平铺）：打开目录 / 新建资源 / 新建文件夹 / 在文件管理器中打开 /
  导入到该目录 / 导出该目录 / 重命名·移动 / 删除目录。
- 资源行菜单（4 项，平铺）：打开资源 / 在文件管理器中打开 / 重命名 / 删除资源。
- 菜单只有 Sidebar 统一渲染一份（`sidebar/index.jsx`），改 RowMenu 即全量生效。

## 方案

### 6.1 RowMenu 支持分隔符

- items 允许 `{ sep: true }`；渲染为
  `<div role="separator" className="gmenu-sep" />`（不可点、不带 run）。
- 普通项渲染逻辑不变。

### 6.2 菜单分组（插入分隔符）

目录行（8 项 → 5 组）：
```
打开目录                      导航
─────────────────────────
新建资源 / 新建文件夹          创建
─────────────────────────
导入到该目录 / 导出该目录      数据交换
─────────────────────────
在文件管理器中打开 / 重命名·移动  位置 / 编辑
─────────────────────────
删除目录                      危险
```

资源行（4 项 → 3 组）：
```
打开资源                      导航
─────────────────────────
在文件管理器中打开 / 重命名     位置 / 编辑
─────────────────────────
删除资源                      危险
```

### 6.3 样式

- `.gmenu-sep`：横向 1px 细线（`var(--line)`），上下各留 4px、左右贴边；
  与菜单整体的粗边框、圆角、黑白单色风格一致，不引入渐变。

- [x] 右键资源：菜单按 3 组分隔（2 条分隔线）
