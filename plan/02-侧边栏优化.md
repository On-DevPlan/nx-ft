# 02 侧边栏优化（P1）

来源：KV nxft id=72 第二条「侧边栏 --- 优化排序有序；右键/省略icon btn 支持更多操作，例如重命名、删除、打开资源操作；支持设置可默认收起」。

主战场：资产域侧边栏 `src/web/frontend/components/asset/side-tree.jsx`（数据与操作）+
通用侧边栏 `src/web/frontend/components/sidebar/`（index.jsx / node-row.jsx / model.js）。
树数据由 `tree.jsx` 的 buildTree 重建，操作在 `use-tree-ops.js`，key 换算在 `tree-keys.js`。

## 子项

### 2.1 排序有序

- 现状：目录按 `order` 字段排序（`tree.jsx` sortLevel → byOrder），同级顺序由拖拽写入（`use-tree-ops.js` onMoveRow）；资源叶子按 `byName` 字典序（`side-tree.jsx`）。
- 目标：**排序有序**——同一层级内顺序稳定、可预期（具体指：手动排序覆盖所有行？还是修某个乱序 bug？原文未给复现，待确认差距）。
- 触点：`tree.jsx`（byOrder/sortLevel）、`use-tree-ops.js`、`side-tree.jsx`（byName）。

### 2.2 右键 / 省略 icon btn 更多操作

- 现状：只有**目录行**有 hover 按钮（重命名/删除，`side-tree.jsx` rowActions）；**资源行无任何行内操作**；无右键菜单。
- 目标：目录行与资源行都支持右键或省略号按钮唤出操作菜单——重命名、删除、**打开资源**（点行已可进编辑页，菜单内再给一份入口）。
- 触点：`sidebar/node-row.jsx`（行渲染）、`sidebar/index.jsx`（renderRowActions 协议）、`side-tree.jsx`（资源行的操作挂接 + useAssetOps 的删除等）。
- **原型记录**（2026-10-16，localtask id=6）：交互已在 `temp/sidebar-2.x-prototype.html` 完整实现并验证——目录/资源行右键与 ⋯ 按钮同一份菜单（打开目录/打开资源、重命名、删除…），删除有确认弹窗（带位置与不可恢复警示），重命名有重名校验。本轮修复原型 bug：右键路径传光标点位无 `bottom`，菜单 y 坐标 NaN 不显示（`rect.bottom ?? rect.top` 兜底）。**待拍板 Q4**（原型审阅面板内）：目录行现 hover 双按钮（改名+删除），原型换成单个 ⋯——替换还是保留双按钮，实现前需定。

### 2.3 支持设置可默认收起

- 现状：展开态已按 `storageKey="nx-ft-side-<kind>"` 持久化（`sidebar/index.jsx`），但无「默认收起」设置——新会话/清存储后回到全展开。
- 目标：提供设置项，默认收起（只留根行/当前路径链），且用户手动展开后仍按现有机制记住。
- 触点：`sidebar/index.jsx`（expanded 初值与持久化）、`sidebar/model.js`（flattenVisible/chainByKey）。
- **原型记录**（2026-10-16，localtask id=7）：`temp/sidebar-2.x-prototype.html` 已实现——侧边栏头部齿轮 → 设置气泡「默认收起（只展开当前链路）」，按领域各存一份（`nx-ft-side-<kind>--default-fold`）；开启后每次进入重算为当前选中链路，手动展开会话内照常记忆；关闭后刷新沿用完整记忆（旧行为）。两条验收均已在原型实测通过。本轮修复原型 bug：`toggleExpand` 存裸路径而非 `dirKey`（`dir:` 前缀）身份，chevron 展开永不生效。

## 实现计划（2026-10-16 原型审阅后拍板）

原型：`temp/sidebar-2.x-prototype.html`（已获用户确认，Q1–Q5 按原型演示行为定案）。

**拍板结论**
- Q1 资源叶子纳入手动排序：**是**。方案对齐目录——`group.json` 的 asset 条目加 `order` 字段，新增 `POST /api/<kind>/asset-reorder`（同组全量重排校验，与 groups-reorder 同款）；无 order 的按名字垫底，与目录一致。
- Q2 新目录/新资源（无 order）排在已排序同级末尾再按名字：**维持现状规则**。
- Q3 目录排序刷新回跳：代码层未见 bug（order 落 group.json，服务端为真相源），不复现；差距主体就是资源不可排序，已由 Q1 方案覆盖。
- Q4 目录行双按钮换单个「⋯」+ 菜单：**替换**。目录与资源行统一 hover「⋯」+ 右键，同一份菜单（打开 / 重命名 / 删除）；删除带确认。
- Q5 「默认收起」按领域各存一份：**是**。存储键 `nx-ft-side-<kind>--default-fold`；开启后每次进入初始展开 = 当前选中链路（现有选中链 effect 兜底），手动展开照常记忆但只在关闭开关后恢复为初值来源。
