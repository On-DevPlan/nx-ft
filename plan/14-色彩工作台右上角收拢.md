# 14 色彩工作台右上角收拢（P1）

来源：KV nxft 任务（DOM 定位 + 用户评论）：`#/color/edit/demo/primary` 的 `div.wb-bar`，
用户评论「色彩管理的右上角也太复杂了」。

## 现状与定位

`asset/workbench.jsx` 的 wb-bar 右侧（html / color 两域共用这份工作台）现在一字排开：

```
[风格 select] [历史 5/5] [新风格] [描述] [大屏模式] [全屏 Studio →] [更多▾] [保存]
```

6 颗按钮 + select + 2 个信息块。实测 930px 视口下已经挤到**两行换行**
（新/风/格、全屏 Studio → 竖着断行）。代码注释里写的编排原则
（「次级按钮按频次 → 次级下拉 → 主按钮」）被后加的按钮一个个撑破了。

## 处理意图

右上角只留**三个动作位**：风格切换（select）、新风格、保存（主按钮），
其余全部收进唯一的「更多」菜单，按作用域分组（与主页面工具条「更多」菜单同一姿势）：

```
[风格 select] [历史 5/5] [新风格] [更多 ▾] [保存]

更多 ▾
  视图    大屏模式（/ 退出大屏）
          全屏 Studio →                      （仅 color 域）
  ──
  风格    风格描述
          删除当前风格
  ──
  资源    改展示名
          删除资源                            （danger）
```

- 可见按钮 6 → 3，换行消失；频次最高的「新风格」保留在明面（与 svg 资源页 ident 行一致）。
- 「更多」菜单沿用 BtnMenuLabel / BtnMenuSep 分组——菜单里「是什么作用域」一眼可辨，
  这正是 13 号任务在 svg 资源页确立的口径：动作按作用域归堆，名字即作用域。
- 历史 5/5 与风格描述内联 span 是信息不是动作，保留原位。
- 所有 testId 不变（wb-style-desc / wb-big / wb-remove-style / wb-rename / wb-remove
  只是搬进菜单），不碰任何行为。

## 改动

- `asset/workbench.jsx`：wb-bar 按钮行重排 + 「更多」菜单分组收拢；
  import 补 `BtnMenuLabel` / `BtnMenuSep`。
