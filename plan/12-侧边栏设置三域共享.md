# 12 侧边栏「默认收起」设置三域共享（P1）

来源：KV nxft 任务「文件夹默认收起 / 侧边栏默认收起——对于三种资源的配置应该是共享的，
不要一个种类一个设置」。

## 现状

侧边栏头部的设置气泡有两条开关：「文件夹默认收起」「侧边栏默认收起」
（`src/web/frontend/components/sidebar/index.jsx`，入口 `head.jsx` 的齿轮）。
落盘 key 挂在 `storageKey` 上，而 `storageKey = nx-ft-side-<kind>`（html / svg / color
各一份，见 `asset/side-tree.jsx`）——于是两条开关也跟着按域各存一份：
`nx-ft-side-svg--default-folders` 与 `nx-ft-side-html--default-folders` 互不相干。

这不合理：这两条是「使用习惯」（进入页面时的初值策略），不是领域数据。
展开记忆（`nx-ft-side-<kind>`）与收起记忆（`--fold`）按域分开是对的——三棵树、
三个宽度状态本来就不通用于三域；但「下次进入默认收不收起」的偏好只有一个用户。

## 目标

两条开关全局一份：`nx-ft-side--default-folders` / `nx-ft-side--default-sidebar`，
html / svg / color 三域读写同一个 key；任一域里改，三个域下次进入同时生效。

展开记忆与收起记忆**维持按域**（树的形状、上次收不收，域与域不同是合理的）——
只动这两条设置。

## 实现

- `sidebar/settings.js`（新）：`loadDefault(name)` / `saveDefault(name, on)` 两个
  react-free 小函数（同目录 `model.js` / `drag.jsx` 的拆法）。load 内建一次性迁移：
  共享 key 没写过时，取三个旧 key（`nx-ft-side-<kind>--default-*`）的「任一为 1」，
  搬进共享 key 后删掉旧键——老用户已开的开关不丢。
- `sidebar/index.jsx`：四处调用点换成共享版；注释同步（说明为什么这两条不分域、
  而 expanded / fold 仍分域）。

## 验收

- [ ] svg 域开「文件夹默认收起」→ 切到 html / color 域，开关同为开，且下次进入初值生效
- [ ] 任一域关掉 → 三域同灭
- [ ] 旧数据迁移：预置 `nx-ft-side-svg--default-folders=1` → 首次读取后共享 key=1、旧键删除
- [ ] 展开记忆 / 收起记忆仍按域各存（svg 的展开不串到 html）
- [ ] `pnpm test` 全绿
