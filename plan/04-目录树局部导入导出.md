# 04 目录树局部导入导出（P1）

来源：KV nx-rh localtask id=2「目录树的右键功能菜单当中需要支持局部导入导出」。

"局部"相对于"整库导入导出"：在目录树里**右键某个目录**，菜单里能把外部资源
导入到该目录，或把该目录（含子目录）导出。目标分组已由右键的目录锁定，不再追问。

主战场：
- 右键菜单：`components/asset/side-tree.jsx` 的 `rowMenu`（目录行）+ 操作 hook `use-tree-ops.js`
- 导入导出核心：`core/svg/set.js`（svg 平铺单文件）、`core/assets/set.js`（html 三件套）
- 上传 / 下载端点：`runtime/zip-upload.js`（/api/<kind>/import.zip）、`runtime/zip-download.js`（/api/<kind>/export.zip）

## 现状（已核实）

- 工具栏的导入导出按钮：`components/svg/zip-io.jsx`（svg）、`components/asset/zip-io.jsx`（html），
  导入时会**再问一次目标分组**（预填当前目录），导出按当前目录 group。
- 后端导入：`importZipBuffer` 收 zip 里所有 .svg（资源名只取文件名、扁平落到目标 group），
  已支持 `group` 参数。
- 后端导出：
  - `group` 模式只导出**该组本身**（`[parseGroupPath(group)]`），**不递归子目录**；
  - `pick` 模式（`[{type:'dir',path} | {type:'asset',key}]`）——dir 项递归包含
    `groupPath === path || startsWith(path + '/')` 全部分组。
  - **html 的 exportZip 已支持 pick；svg 的 exportZip 只支持 group、不支持 pick**。
- 路由层 `zip-download.js` 已把 `group / style / pick` 都解析并传给 exportZip。

## 方案

### 4.1 后端：svg exportZip 补 pick（对齐 html）

- 触点：`core/svg/set.js` 的 `exportZip`。
- 改动：pick 存在时按选区展开——
  - dir 项：scanGroups 取该目录及其所有子分组（递归），遍历其中资源；
  - asset 项：loadGroup 取单个资源；
  - 去重（整选目录与子项混选时同一资源只取一次）。
- 条目仍是 svg 平铺单文件（`${gp}/${name}.svg`），与 html 三件套约定不同。
- 文件名 scope：pick 用 `${kind}-pick-<n>`，与 html 对齐。

### 4.2 命令式 hook：use-zip-io

- 新增 `components/asset/use-zip-io.js`，kind 驱动、html/svg 共用（URL 模式一致）。
- 暴露：
  - `importToGroup(group)`：记住目标 → 编程拉起隐藏 file input（.zip）→
    `apiUpload('/api/<kind>/import.zip', file, {query:{group, style:'default','label-from':'title'}})`
    → 结果弹窗（导入/跳过逐条；html 显示 slots，svg 不显示）。
  - `exportGroup(group)`：`fetch('/api/<kind>/export.zip?pick=<dir 项>')`（用 pick 递归）
    → 取 Content-Disposition 文件名 → 触发下载。
  - `node`：隐藏 file input + portal 到 body 的结果 Modal。
- 与两个按钮组件的区别：按钮组件是渲染按钮、导入再问分组；这里命令式、分组锁定，
  供右键菜单 run 回调调用。

### 4.3 接入右键菜单

- `components/sidebar/icons.jsx`：新增 `ImportGlyph`（托盘 + 向下箭头）、`ExportGlyph`（托盘 + 向上箭头）。
- `use-tree-ops.js`：调用 `useZipIo(kind, { onChanged: refresh })`，暴露
  `importToDir(node)` / `exportDirRow(node)`（rel 由 `relOfKey(node.path)` 取），把弹窗 node 合并返回。
- `side-tree.jsx`：
  - 目录行 `rowMenu` 在"在文件管理器中打开"之后加"导入到该目录""导出该目录"两项；
  - 渲染 zip-io 的弹窗节点。

- [ ] 右键目录 → 导出该目录：下载 zip，含该目录**及所有子目录**资源
