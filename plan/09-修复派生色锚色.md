# 09 修复全屏 ColorStudio 派生色锚色（P1）

来源：KV nx-rh localtask id=4「全屏颜色工作台里的派生色，锚色是无效的，整个功能都没有
效果，没有办法实时响应」。

## 根因（已定位）

全屏 ColorStudio 的「当前选中规则 / 色轮派生标记」都读 `doc.viewState.selectedHarmony`：

- 规则按钮高亮：`ColorWheel.jsx`——`doc.viewState.selectedHarmony === opt.value`
- 色轮上的派生标记：`HarmonyOverlay` 的 `type` = `doc.viewState.selectedHarmony`

但 `colorStudioStore.load()` 构造初始 doc 时，`viewState.selectedHarmony` **硬编码为
null**，没有从活动调色板的 `palette.harmony.type` 初始化：

```js
viewState: { ..., showHarmony: false, selectedHarmony: null, ..., selectedColorId: null }
```

于是一个 data 里明明存了 `harmony:{type:"monochromatic", anchorColorId, ...}` 的调色板，
重新打开全屏 Studio 后：规则按钮显示「无」高亮、色轮上不画派生标记——用户看到的就是
「锚色无效、整个功能没效果」。`selectedColorId` 也没回到锚色，色轮指示与派生覆盖层
对不上。

## 修复

### 9.1 load 时从活动调色板初始化 viewState（colorStudioStore.js）

- 确定活动调色板（`?palette=` 覆盖，否则第一个）。
- `selectedHarmony` = 活动调色板 `harmony?.type ?? null`
- `showHarmony` = `harmony != null`
- `selectedColorId` = `harmony?.anchorColorId ?? null`（色轮回到锚色，覆盖层 sourceHex 对齐）

### 9.2 实时响应（核对，不另起逻辑）

- 勾选「锚色变化自动重派生」后，拖色轮改锚色 → `useAutoFillEffect` 指纹变化 →
  applyAutoFill 重派（已实现，需实测）。
- 切换规则时 force 立即派生一次（已实现）。
