# 07 色彩实时预览：整模块撞色（P1）

来源：KV nx-rh localtask id=3「色彩资源模块实时预览，实现整个预览模块的撞色，而不是
现在的小卡片，更加具有视觉冲突一些」。

色彩编辑工作台右侧的实时预览，现在把每个颜色渲染成一枚**白底小卡片**（120px 宽、
56px 高色块 + hex + note，flex 网格 + 灰底 + 卡片间距），颜色被卡片框住、彼此不相邻，
看不出"撞色"。本次改为**整模块被颜色填满的大色块墙**：色块大、直接相邻、强对比，
文字叠在色块上。

主战场：
- 预览文档组装：`components/preview/doc.js` 的 `buildColorDoc`（color 唯一预览拼法）

## 现状（已核实）

- `buildColorDoc(code)` 把 data JSON 解析为 palettes，每个颜色渲染
  `.sw`（白底、边框、圆角、120px 宽）→ `.chip`（56px 色块）+ `.meta`（hex / note）。
- 网格 flex-wrap、gap 8px、灰底 `#f5f6f7`——颜色被白色卡片和间距隔开，是"小卡片"。
- 预览在手机框 iframe 里渲染（工作台右侧），完整编辑体验在全屏 ColorStudio。

## 方案：撞色色块墙

### 7.1 大色块铺满、颜色直接碰撞

- 去掉灰底、白卡片、边框、圆角、间距：`.wall` 用 2 列 grid、**gap 0**，颜色直接相邻。
- 第一个色（主色）= `.hero` 占满整行（`grid-column:1/-1`），min-height 更大；
  其余色块 2 列、等高；最后一个若落单则占满整行。
- `.wall` 填满整个视口（`min-height:100vh`），色块 min-height 足够大，铺满手机框。

### 7.2 文字叠在色块上，自动对比色

- hex / note 直接叠在色块上（不再有白底 meta 区）。
- 按色块**感知明度**（0.299R + 0.587G + 0.114B）决定文字色：浅色块用 `#14161a`、
  深色块用 `#fff`，保证强色块上文字仍可读。
- 调色板名叠在 hero 色块顶部（大字），不再单独占一行 h2。

### 7.3 视觉冲突

- 相邻色块即调色板自身的对比/互补色（harmony 决定），gap 0 时直接撞在一起；
- 大色块 + 满铺 + 文字反色，形成"整面墙"的视觉冲击，而不是一排安静的小卡片。
