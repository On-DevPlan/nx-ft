# 17 颜色面板并入编辑器平面（P1）

来源：KV nxft 任务（DOM 定位 + 用户评论）：`#/svg/edit/...` 资源页的
`div.cp.cp--open`（颜色抽屉），评论「没必要单独一个区块，直接在编辑里面添加一个模块，
支持配置颜色变量就行了；在 svg 编辑附近或者 svg/css/js 的平面添加一个颜色的面板，
提供颜色看板和选项，保留现在的自动检测色彩和 binding」。

## 现状与定位

svg 资源页（`svg/detail.jsx`）右栏预览下方挂着一个可折叠的「颜色」抽屉
（`svg/color-panel.jsx`，plan/10 引入）：收起时一条工具条（颜色 / 提示 / 重置），
展开后是颜色槽（主题色 + 自动检测的硬编码色）与 color 域调色板色板。
它独立于编辑区自成一块版面——用户要点开抽屉、再回到编辑器，两块来回跳。

## 处理意图

颜色配置是**编辑平面的一部分**，不是预览的附件——把它做成 MultiPaneEditor
（svg / css / js 页签所在的编辑器）里的一个**「颜色」页签**：

- 与 svg / css / js 同层：同一条页签条、一样能拖动合并 / 分栏 / 记忆布局
  （`code-workbench` 新增通用 `extras` 插槽：`{ [slotId]: { label, render } }`，
  非代码模块页签；html / color 工作台不传不受影响）。
- 面板体撑满页签面板：说明 + 重置一行，颜色槽一行，色板网格吃掉剩余高度滚动；
  抽屉的开合状态、独立工具条全部删除。
- **自动检测与 binding 原样保留**：硬编码色收集（fill/stroke/color 字面量）、
  主题色 / 局部色的预览层替换、color 域调色板色板加载。
- 预览栏不再有颜色块，右侧只剩预览本体。
- 布局迁移：页签全集从 [svg,css,js] 变为 [svg,css,js,color]，老布局快照对不上
  → 回退单面板默认布局（点过「设为默认布局」的用户会重排一次），可接受的迁移。

## 改动

- `code-workbench/index.jsx` / `view.jsx`：`extras` 插槽（页签全集 = 代码 + 模块；
  布局按全集持久化；模块页签渲染 `extras[slot].render()`）。
- `svg/detail.jsx`：ColorPanel 以 extras 挂进编辑平面；预览栏移除。
- `svg/color-panel.jsx`：去掉抽屉壳（开合 / toggle），只留面板体。
- `styles/preview.css`：`.cp` 从抽屉样式改为撑满页签面板的模块样式。
