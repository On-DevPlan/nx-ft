## 现状核实（动手前第一步）

浏览模式**看起来已经**是当前目录视图：子目录以卡片展示（`dirNode.children`）+ 资源取当前目录直接资产。
但提交方仍提出此需求，说明存在某个面仍在显示子文件夹内容。候选差距（按可能性排）：

1. **结果视图**（`manage-result.jsx`）：有搜索/标签筛选时跨全部目录展示——若提交方认为「主页面的筛选结果也应限当前目录」，这是差距所在
2. **根「全部」页**：`dir=''` 时 `dirGroup` 为 null 只出文件夹卡片——确认根页是否仍拼入了任何平铺资产
3. **SubdirCard 内容**：卡片上的数量/预览是否泄露了子文件夹内部内容（`total` 含后代资源）
4. **SVG 工作台**（`svg/workspace.jsx`）或画廊页的另一套目录逻辑

核实方式：跑 `pnpm dev` 逐面检查，或直接问提交方复现路径。

## 目标

- 浏览模式只呈现**当前目录**的直接子项：文件/文件夹，不渲染任何子文件夹的内部内容
- 筛选/搜索若保留跨目录语义，需在 UI 上明示（或限当前目录，随核实结论定）
