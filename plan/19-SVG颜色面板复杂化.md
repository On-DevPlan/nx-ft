# 19 SVG 颜色面板复杂化（P1）

来源：KV nxft 任务「SGV-颜色控制 需要支持更加复杂的颜色面板 最好直接导入颜色选择器组件」。

## 现状与定位

plan/17 把颜色面板从「预览下方的独立抽屉」搬进编辑平面，成了与 svg / css / js
同排的「颜色」页签。但面板体本身还是 plan/10 那一版：

- 一个**平铺的色块网格**（color 域所有调色板的颜色混在一片）+ 一个槽位胶囊行；
- 想调一个非现成的颜色，只能去色板里找——色板里没有就得改源码；
- 几十个调色板平铺在一起，谁是谁分不清。

也就是「能选色」但谈不上「颜色控制台」。

## 处理意图

把面板做成真正的**颜色控制面板**：引一个现成的取色器组件当核心，配齐数值输入、
派生色、对比度与分组色板。

- **直接引组件，不自己画**：拖拽 + 色相映射 + 边界吸附 + 键盘可达性全要自己兜。
  选 `react-colorful`（3.1KB、零依赖、`react >=16.8` peer）：一个
  `HexAlphaColorPicker` 就含饱和面 + 色相条 + 透明度条，值域直接是 8 位 hex，
  自带 `role="slider"` 与方向键操作。
- **三种数值口径**：HEX / RGB / HSL 切换，输入即改色（编辑期本地文本，
  失焦 / 回车才提交——受控输入清空时会把「空」当 0 提交，颜色会莫名其妙跳一下）。
- **透明度**：SVG 颜色本来就支持 8 位 hex / rgba，图标做半透明描边是常见诉求。
- **和声派生**：互补 / 三角 / 类似 / 分裂互补 / 单色，一键把配套色套到当前槽。
- **对比度提示**：当前色压白字还是压墨字、跟白底黑底各多少比值（WCAG）。
- **色板分组**：按调色板分组（原来平铺一片），带搜索过滤 + 「最近使用」
  （localStorage，最多 16 个）。
- **语义不变**：仍只作用于预览层、不写脏源码；自动检测的硬编码色、变量槽、
  主题色槽原样保留（plan/18 的三种调色原理一根没动）。

## 变量名可自定义 + 主题色显示对应名称

- **每个槽显示它在 SVG 里的对应名称**：主题色 → `currentColor`（SVG 原生语义，
  预览注入 color 驱动它），变量槽 → 变量名本身，字面量槽 → 原色值。
  一眼能看出「这个色到底叫什么」，而不是只看到一个「主题色」。
- **变量名可改**：选中变量槽 → 出现「变量名」行 → 改名 → **写回源码**
  （声明块里的名字与全文 `var(--old …)` 用法一起改，只改名字不改色）。
  这是写源码的动作（不是预览层替换），所以进脏态、待保存。
  校验：名字必须 `--` 开头、字母/下划线起，且不与已有变量重名。
- **改名时预览层的覆盖值跟着迁**：覆盖值是按变量名存的（`theme.vars[名]`），
  键换了值还挂在旧键上，这个槽的调色就「丢」了——改名时一并迁移。

### 引擎侧的三处配套修正（否则改名不可靠）

1. `parseVarDecls` 的声明正则写死了 `--c-` 前缀 → **自定义名根本认不出来**，
   改成认任意 CSS 自定义属性。
2. `migrateToVars` 只收「本次新迁的变量」，会把已有声明块整体替换掉 →
   **改过名之后再迁一次，用户起的名字连同它声明的值一起被抹掉**。
   改成：已有声明原样保留；字面量与已有变量同值时复用该变量；新变量按
   「实际占用的名字」避让（`--c-1` 被改名后是空出来的，可再被占用）。
3. 迁移只认属性（`fill="#x"`）与 `<style>` 块，**不认 `style="fill:#x"`**
   ——而后者是更常见的写法，用户点了「迁移为变量」却什么都没发生。
   补上：style 属性里的字面量同样迁（引号沿用原来的）。


## 改动

- `components/svg/color-vars.js`：新增 `renameVar`（声明 + 用法一起改）与
  `isValidVarName`；`migrateToVars` 改为保留已有声明、同值复用、避让同名；
  迁移补上 `style="fill:#x"` 里的字面量。
- `components/svg/color-utils.js`（新，纯函数）：颜色解析 / 规范化 / 三口径格式化 /
  和声派生 / 对比度 / 最近使用色。走 culori（已在依赖里）。
- `components/svg/color-palette-api.js`（新）：color 域调色板加载（分组返回，
  分组之间并发——原来一条条串行等，面板空着不出东西）。
- `components/svg/color-picker.jsx`（新）：取色卡（react-colorful + 数值输入 +
  透明度 + 和声 + 对比度）。
- `components/svg/color-parts.jsx`（新）：槽位胶囊 + 分组色板 + 最近使用。
- `components/svg/color-panel.jsx`（重写）：主体——状态（选中槽 / 调色板 / 最近使用 /
  改名草稿）、接线（选色写回 theme、改名写回源码）、布局。
- `components/svg/detail.jsx`：接线改名动作（写编辑器 → 脏态）。
- `styles/color-panel.css`（新）：面板样式独立成层（原来塞在 preview.css 里，
  那是「预览容器」层）；`style.css` 增 import，preview.css 里的旧 `.cp` 规则删除。
- `tests/unit/svg-color-vars.test.mjs`：改名 / 迁移保留 / style 属性迁移等用例。
