# 16 侧边栏全量右键菜单：根行与空白处（P1）

来源：KV nxft 任务（DOM 定位 + 用户评论）：`#/svg` 侧边栏根行 `div.grow.on.root`
（「SVG 资源 96」），评论「右键需要支持右键菜单功能——这个根下面右键无法触发菜单，
整个左侧边栏包括空白都应该提供右键菜单」。

## 现状与定位

右键菜单协议已存在：`node-row.jsx` 的 `onContextMenu` + `rowMenu(node)`（side-tree.jsx
构建条目，`sidebar/row-menu.jsx` 统一渲染，plan/05 已给目录行加了「新建」簇）。但：

- **根行**（`root:<kind>` 整树行）被显式排除：`rowMenu && !isRoot` 同时挡掉了右键与
  「⋯」按钮——注释理由是「它是回到最外层的落点，不该有删除之类的语义」，结果连
  创建与定位也没有；
- **树空白处**（区标题、提示行、容器空隙）没有任何右键响应。

## 处理意图

「整个侧边栏都有右键」补齐两处，内容与各自的作用域对齐：

| 右键位置 | 菜单 | 与既有语义的对齐 |
| --- | --- | --- |
| 根行 / 树空白处 | 新建资源 · 新建文件夹 · 在文件管理器中打开 | 空白处的**拖拽落点本就是「最外层」**，右键创建的父级锁定同一处（`relOfKey('root:<kind>') = ''`）；删除类语义依然不进这份菜单（与根行「不可删」的旧约束一致） |
| 目录行 / 资源行 | 不变（plan/05 / plan/02 的既有簇） | — |

「在文件管理器中打开」对根行有一个语义缺口：后端 `revealDir` 的 `parseGroupPath('')`
直接报「分组路径不能为空」，前端只好用 `HOME_DIR`（未分类）替代——根 ≠ 未分类。
补齐：`reveal` 动作的 `group` 参数改为可选，`revealDir` 对「不带 group 也不带 name」
短路到本域根目录（`groupsRoot(kind)`）；CLI `ft <kind> reveal` 裸命令同样受益。

## 改动

- `core/assets/groups.js`：`revealDir` 空组短路到本域根目录。
- `core/assets/actions.js`：`reveal` 的 `group` 参数 `required: false`，summary 同步。
- `asset/use-tree-ops.js`：`revealRow` 对根行 / `null` 走 `group: ''`。
- `asset/side-tree.jsx`：`rowMenu` 加根分支（`!node || node.kind === 'root'`）。
- `sidebar/node-row.jsx`：根行放开右键与「⋯」。
- `sidebar/index.jsx`：树容器 `onContextMenu`（目标不在 `.grow` 行上时弹
  `rowMenu(null)` 的菜单）。

## 验收

- [ ] 根行右键 / hover「⋯」/ 树空白处右键 → 同一份「最外层」菜单；目录行 / 资源行菜单不变
- [ ] 空白处右键 → 新建文件夹 → 对话框标题「在最外层 下新建文件夹」，建完跳转（数据用后即清）
- [ ] 根行「在文件管理器中打开」请求 `group: ''`，后端短路返回本域根目录（验证时拦截网络层，不真弹窗口）
- [ ] CLI `ft <kind> reveal` 裸命令语义 = 打开本域根目录（代码路径与面板同一条）
- [ ] `pnpm test` 全绿
