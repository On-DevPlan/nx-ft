# 11 工具栏位置控制：拖拽优先（P0）

来源：KV nxft 任务「对于 svg 自定义工具栏 —— 对于自定义工具栏，位置的控制尽量不点击，
支持拖拽操作，支持拖拽到位置以及拖拽进行排序，深入优化」。

主战场：`src/web/frontend/components/asset/toolbar-layout-panel.jsx`（自定义工具栏面板，
html / svg / color 三域共用，svg 域经 `SvgDrive` → `ManagePage` → `ManageBar` 进入）。

## 现状与问题

面板已经能编排，但**位置只能靠点**：每行 `↑ ↓` 两个按钮调次序、`→ 右 / → 左` 换区。
已有的拖拽只覆盖「行与行之间」这一条窄路，且有几处硬伤：

1. 只有「拖到另一行上」一种落点，没有前/后之分——想插到某行之后无处可落（末尾尤其明显）。
2. 左区为空时没有落点（空列表里什么都没有），挪不进去，只能点「→ 左」。
3. 菜单项要上工具栏，必须先勾「快捷显示」，再回到上面列表里拖到位置——两步、且中间态被迫可见。
4. 顶部预览条是纯展示，位置就在眼前却不能直接拖。
5. `dragIdx` 只写不复位（没有 `onDragEnd`），拖到面板外松手后残值留在 ref 里，
   下一次落点会拿它当拖动源。
6. 老 layout 里「+ 新建」若不在数组末位（手改过 localStorage / 早期版本写入），
   面板按渲染序兜底排序过，但插入位次算的是数组序，两套口径会错位。

## 目标

**位置控制 = 拖拽；点击只留给「显隐 / 快捷显示」两个开关**（那两件事拖不出来）。

落点语义（一处定义，面板各处共用）：

| 拖到哪 | 结果 |
| --- | --- |
| 某行的上/下半 | 插到它前 / 后（含跨区：同时换区） |
| 区列表的空白处 | 该区末位 |
| 左区间 `│` 的左右半 | 左区末位 / 右区首位 |
| 主按钮「+ 新建」上 | 插到它之前（等价右区末位——它恒末位） |
| 「更多菜单」卡片 | 从工具栏摘下来（quick = false，菜单里保留） |
| 从「更多菜单」卡片拖到工具栏 | 加为快捷按钮（quick = true）+ 落点插入，一步到位 |
| 预览条上的 chip | 同一份编排：就近站位、跨过 `│` 即换区 |

键盘（同样不点）：「Alt+↑↓」换位次、「Alt+←→」换区，行 `tabIndex=0`，`focus-visible` 可见。
行内 `↑ ↓ →左 →右` 按钮保留为兜底，但只在悬停 / 键盘聚焦时出现，默认不占视觉。

不合法落点：主按钮（拖不动、也不被越过）、原生项（面包屑/搜索/更多）拖进菜单卡片
（它不是菜单成员）。这类落点既不提示也不 `preventDefault`，让浏览器自己显示禁止光标——
与侧边栏 `drag.jsx` 同一口径。

## 实现

拆成三层，判定只此一处：

- `asset/toolbar-modules.js`（新）：`MODULES` 模块表 + `metaOf / isMenuItemId / effZoneOf /
  onBarOf / isLocked / normalizeLayout`。面板与栏渲染共用同一份判定，且**不牵 react**，
  排序内核能在 node 里单测。
- `asset/toolbar-dnd.js`（新）：纯函数排序内核 `moveModule(layout, { id, anchorId, after,
  zone, quick })`、`setFlag`、`isMenuOnly`。数组次序 = 渲染次序，`zone` 决定左/右区，
  于是「段内排序 / 跨区挪位 / 菜单项上栏」是同一件事：把一项挪到一个位次。
- `asset/toolbar-layout-panel.jsx`：DOM 判定（行高比例选前/后）+ 拖拽状态。沿用侧边栏
  `drag.jsx` 的踩坑结论：**判定只读 ref，state 只用于画**（dragstart → dragover 同帧时
  React 未重渲染，只读 state 会让判定读到旧值）。

`useToolbarLayout.js` 只留持久化（load / migrate / 写回），load 时过一遍 `normalizeLayout`
把锁定项扶到末位、去掉重复 id。`manage-bar.jsx` 改从 `toolbar-modules.js` 取判定，
删掉自己那份同名实现（两处口径，迟早分叉）。

## 验收

- [ ] 面板内可拖动排序：行上/下半 = 前/后插，落点有插入线；拖动中源行降透明度
- [ ] 跨区拖动（含拖进空区）落点正确，无需点「→ 左 / → 右」
- [ ] 「更多菜单」里的项直接拖到工具栏 = 加为快捷按钮并落在落点；拖回菜单卡片 = 摘下来
- [ ] 预览条 chip 可直接拖动排序 / 换区
- [ ] Alt+↑↓ / Alt+←→ 不点鼠标能换位次与换区
- [ ] 「+ 新建」拖不动、也不被任何落点越过（面板 + 栏两处一致）
- [ ] 保存后刷新保持；老 layout（乱序 / 重复 id / 旧字段）load 后被归一
- [ ] 真机浏览器里三域（html / svg / color）面板都能拖（svg 域为验收主场景）
- [ ] `pnpm test` 全绿（lint + build + smoke + unit + uiux:score）
