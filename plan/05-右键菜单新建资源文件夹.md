# 05 右键菜单新建资源 / 文件夹（P1）

来源：KV nx-rh localtask id=5「目录树的功能工作菜单需要支持新建资源或者新建文件夹」。

在目录树里**右键某个目录**，菜单里能直接在该目录下新建子文件夹、或新建资源。
目标父分组已由右键的目录锁定，不再追问分组路径，只问名字。

主战场：
- 右键菜单：`components/asset/side-tree.jsx` 的 `rowMenu`（目录行）+ 操作 hook `use-tree-ops.js`
- 新建端点：`POST /api/<kind>/groups`（建分组）、`POST /api/<kind>/assets`（建资源）

## 现状（已核实）

- 侧边栏头部「新建文件夹」按钮：走 `use-tree-ops.js` 的 `createAtSelected(name)`，
  落在**当前目录**（`currentDir`，由 hash 派生），建完 `goDir` 跳进去。
- 内容区（管理页 / 工作台）的新建：`useManageOps.js`：
  - `createGroup(parent, name)`：`POST /api/<kind>/groups`，body `{group: parent/name}`；
  - `createAsset(parent, name)` / `addAsset(parent)`：`POST /api/<kind>/assets`，
    body `{group, name, label?}`，建完 `onOpen` 进编辑器。
- 右键目录菜单当前项：打开目录 / 在文件管理器中打开 / 导入到该目录 / 导出该目录 /
  重命名·移动 / 删除目录——**没有"新建"**。
- 资源编辑器路由：`#/<kind>/edit/<group 路径>/<name>`（group 段逐段 encode）。

## 方案

### 5.1 use-tree-ops 加两个命令

- 触点：`components/asset/use-tree-ops.js`。
- `createSubDir(node)`：在右键目录下新建子文件夹——
  - 对话框问文件夹名（kebab-case，单段）；
  - 路径 = `relOfKey(node.path) + '/' + name`；
  - `POST /api/<kind>/groups`，body `{group: path}`；
  - `refresh()` + `goDir(path)`，与 `createAtSelected` 同收尾。
- `createAssetInDir(node)`：在右键目录下新建资源——
  - group 锁定为 `relOfKey(node.path)`；
  - 对话框问资源名（kebab-case，单段）；再问展示名（可回车跳过）；
  - `POST /api/<kind>/assets`，body `{group, name, label?}`；
  - `refresh()` + 跳编辑器 `#/<kind>/edit/<group>/<name>`（与资源行 nav 同格式）。

### 5.2 图标

- `components/sidebar/icons.jsx` 新增：
  - `NewFolderGlyph`：文件夹 + 角标加号（新建文件夹）；
  - `NewFileGlyph`：文档 + 角标加号（新建资源）。

### 5.3 接入右键菜单

- `side-tree.jsx` 目录行 `rowMenu`：在"打开目录"之后加"新建资源""新建文件夹"两项
  （高频创建操作，紧随打开；先资源后文件夹，与内容区"+ 新建"菜单次序一致）。
- 资源行菜单不加（资源下不能再建）。
