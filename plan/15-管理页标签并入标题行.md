# 15 管理页标签筛选并入标题行（P2）

来源：KV nxft 任务（DOM 定位 + 用户评论）：`#/svg` 的 `div.tag-cloud`
（category 45 / color 45 / motion 1 / outline 1），用户评论「这里的 tag 放在这不好看，
想办法优化」。

## 现状与定位

`asset/manage.jsx`（html / svg / color 三域的管理页共用）版面从上到下：

```
[ShellBar 工具条]
[am-head   SVG 资源 · 4 个分组 · 145 个图标]
[tag-cloud  category 45 | color 45 | motion 1 | outline 1]   ← 独占一整行
[内容区]
```

标签云是**筛选轴**（点 chip = AND 筛选，出现「清除筛选」），却独占一个版面块：
4 颗 chip 浮在整行宽度的左侧，右侧全空，看起来像一块没排进去的游离内容——
这就是「不好看」的来源。`svg/workspace.jsx` 里还有一处 TagCloud，但该组件已无路由
（#/<kind> 全部走 ManagePage），不在本次范围。

## 处理意图

筛选轴不该自己占一块版面，它是标题行的补充信息——**并入 am-head 右侧**：

```
[am-head   SVG 资源 · 4 个分组 · 145 个图标        (category 45)(color 45)(motion 1)(outline 1)]
```

- 左侧标题与统计、右侧筛选 chips，一行读完；无标签时 TagCloud 返回 null，版面不变。
- 筛选生效时「清除筛选」chip 照旧出现在行内；chip 多时沿用现有 max-height 88px +
  滚动护栏，am-head 本就 flex-wrap，放得下就同排、放不下折行。
- 只动位置与对齐，不碰筛选逻辑与 DOM 结构（`.tag-cloud` / `.tag-chip` 原样）。

## 改动

- `asset/manage.jsx`：`<TagCloud>` 移入 `.am-head` 行尾。
- `styles/asset-manage.css`：`.am-head .tag-cloud { margin-left: auto; }` 一条对齐规则。
